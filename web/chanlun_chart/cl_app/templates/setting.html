03

配置指南

完成飞书机器人授权并取得应用凭证。

  1. 打开飞书开放平台并登录。
  2. 在开发者后台创建“企业自建应用”，添加机器人能力。
  3. 在权限管理中开通 contact:user.employee_id 与 im:message。
  4. 创建版本并发布应用，然后从“凭证与基础信息”复制 App ID 与 App Secret。
  5. 通过飞书 API 调试台按手机号查询 User ID，并填入上方字段。
!
