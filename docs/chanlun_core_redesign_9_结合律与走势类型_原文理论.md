## 1. 结合律：能"组合"的代数根基

- **走势类型的连接运算符合结合律**：`A+B+C = (A+B)+C = A+(B+C)`，A/B/C 级别可不同
  （line 23950 / 24140）。
- **但不符合交换律**（line 23950）——这是该运算的特别之处。
- 由结合律推出 **走势分解定理一**：任何走势 = 同级别「盘整/下跌/上涨」三种走势类型的连接
  （line 7270 / 23950）。

### 1.1 多义性（≠ 含糊性）
- 由结合律，**同一段已完成走势有多种合法分解**，每种都不违反理论（line 24140 / 24195）。
- 多义性是「严格理论的不同视角」，好比给方程设不同参数（line 24140 / 24720）。
- 「无论怎么组合，都不会出现违反理论的情况」（line 24195）。

## 3. 中枢的精确定义

- **中枢 = 某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分**（line 7260-7261）。
- 递归到最低不可分级别 → 三个该级别 K 线重叠（line 7261）。
- **盘整 = 完成的走势类型只含 1 个中枢**；**趋势 = 至少含两个以上依次同向的中枢**（line 7264-7265）。
- 升级时：**把次级别走势当线段，小括弧（每组）都是线段，高低点就是这线段的端点**，
  中枢区间 = 重叠（line 30931）。→ 印证项目"摆动法/端点高低点"。

## 4. 走势类型的精确结构与边界

### 4.1 标准趋势结构 `a+A+b+B+c`（line 20094-20095）
```
   a        A         b        B        c
进入段 + 第1中枢 + 连接段 + 第2中枢 + 离开段
(次级别)  (本级中枢) (次级别)  (本级中枢) (次级别)
```
- **趋势 = ≥2 个依次同向中枢**（A、B 同向）；
- 按次次级别计：`1+3+1+3+1 = 9 段` —— **9 段的来历**（line 20095）；
- 30 分钟盘整（1 中枢）= ≥9 个 1 分钟走势类型（数量平衡，line 20100）。

### 4.2 走势终完美 = 边界（line 7248-7260）
- 基本原理一：**任何级别的任何走势类型终要完成**（「走势终完美」）。
- 一旦某类型走势完成，**就转化为其他类型**——连续两个走势类型必是不同类型
  （上涨完了只能接盘整或下跌）。

### 4.3 边界的"当下"判定（line 22542-22547）— 落地关键
- **趋势靠"三类点"生长**：5 分钟离开中枢后 **不背驰** + **回拉不回中枢（三类点）**
  → 下一个同向中枢出现，趋势继续（「不背驰，就意味着还有第三个中枢出现，如此类推」）。
- **趋势靠"背驰"终结**：离开段背驰（c 与 b 比，line 22415）→ 第一类买卖点 → 转折 →
  走势类型边界。
- 背驰判据：MACD 力度衰减（绿柱比上次缩短、而股价 continue 创新低，line 3554）；
  本项目背驰提高一级别用 MACD（`macd_htf`）。
- 第一类买卖点 = 背驰式转折后构成（line 3544）。

### 4.4 中枢扩展 vs 走势连接（line 20105）— 精确区分
- **扩展 = 一个未完成走势类型内部的中枢变大，仍在一个走势类型里**；
- **连接（如"下跌+盘整"）= 两个已完成走势类型并列**；
- 例：`a+A+b+B+c` 中 `B+c` 扩展 → `a+A+b`=a~、`B+c`扩展=A~，整体 `a~+A~`，
  可演化成 `a~+A~+b~+B~+c~`（扩展成更高级别下跌）。

## 6. 三类买卖点（中枢/盘整的终结 + 升级触发）

- **三类点定理（line 30661）**：次级别走势类型向上离开中枢，再以一个次级别走势类型回试，
  **低点不跌破 ZG → 三类买点**；向下离开、回抽、**高点不升破 ZD → 三类卖点**。
  → 项目 termination「离开不回」与此逐字一致（连用 ZG/ZD 的细节都对）。
- **三类点至少 5 段（line 33045）**：前 3 段构成中枢、第 4 段离开、第 5 段构成三类点。
- **升级触发（line 30663 / 37 课 line 30664-30667）**：离开段 c 若是「含 ≥2 个次级别中枢的
  次级别趋势」、且第二个中枢未触及老中枢 → 三类点确认 → 升级；趋势的 c **必须创新高/新低**。
- **买点定律（line 3562）**：大级别第二类买点 = 次级别相应走势的第一类买点（项目 P5b 已实现）。

## 7. "最合理分解"的判据 + 结构约束

### 7.1 选最优组合（line 30924-30927）🎯
> 哪种分解都合法，但要 **选"当下有明确意义"的分解 —— 即能让「中枢震荡」或「第三类买卖点」
> 最清晰的那个**（从方便操作的角度）。

### 7.2 结构约束（line 30920）
- **两个同级别中枢之间必须有次级别的走势连接**；
- ⚠ 例外：扩展成高一级别中枢的"3 个括弧相加"允许相邻无次级别（那是升级，非两同级别并列）。
