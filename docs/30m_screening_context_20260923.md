# 选股页 30m 背景证据

## 原文与实现的边界

- **原文**：30 分钟中枢涉及三个 5 分钟走势类型；30 分钟反弹可按 5 分钟节奏处理。出处：`D:\缠论\chanlun_lesson_corpus\L107_如何操作短线反弹(2008-08-19161039).md` 第 109–112、139–142 行。
- **原文**：完成的单中枢走势类型是盘整；完成的趋势至少有两个依次同向的中枢。出处：`D:\缠论\chanlun_lesson_corpus\L017_走势终完美(2006-12-18115242).md` 第 268–283 行。
- **原文**：第一中枢后的第三类买点及后续非背驰向上与上升趋势形成有关；第三类买点后并不必然形成趋势。出处：`D:\缠论\chanlun_lesson_corpus\L107_如何操作短线反弹(2008-08-19161039).md` 第 165–181 行，以及 `D:\缠论\chanlun_lesson_corpus\L020_缠中说禅走势中枢级别扩张及第三类买卖点.md` 第 427–455 行。
- **工程推导**：不能要求“30m 已完成上涨趋势”才保留 5m 首中枢三买，否则会排除上涨起始阶段。30m 背景是独立、可选的排序/筛选证据，不改变 5m 买卖点或 1m 区间套状态。这里的“当前向上”仅指本系统在本轮截止时刻具有正在形成的 30m 上涨走势或向上线段证据，并非原文另设的买点名称。

## 数据口径

全市场 5m 扫描与实时监听照常运行。每轮选股完成且监听任务空闲后，后台只对已确认 5m 买卖点的去重标的独立读取 30m 收盘 K 线，使用该标的本轮 5m 的 `source_closed_at` 为唯一截止时刻。30m 截止时间不一致、行情不完整、日历不可用或结构无当前证据时标为“未知”。每条结果保存行情输入指纹、数据状态、30m 走势类型、线段、证据时间和失败原因，并以任务 ID、源码版本及标的截止时刻绑定；旧轮不混用新轮证据。

分类只使用截止时刻仍在形成的 30m 走势类型，或该时刻仍在形成的 30m 线段。已经结束、仅在历史中出现的上涨走势不标为“当前向上”。页面默认显示所有候选，可选当前向上、上涨走势形成中、向上线段、当前向下、盘整、未知。后台最多使用两个独立计算进程；若新的实时监听任务开始，尚未提交的 30m 标的暂停计算，避免挤占监听。
