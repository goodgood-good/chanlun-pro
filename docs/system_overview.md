# 缠论图表分析系统说明

本说明对应 2026-09-12 精简后的代码。当前产品范围为行情与本周期结构分析；买卖点、背驰、走势分解、选股、模拟和回测需要另行实现后才能恢复。

## 页面和操作

| 页面 | 入口 | 功能 |
| --- | --- | --- |
| 登录 | `/login` | 账号登录、会话与个人布局隔离 |
| 主图 | `/` | 默认单周期 K 线、笔、线段、中枢、指标、画线 |
| 自选管理 | `/zixuan_group/<market>` | 分组增删、组内标的管理、跨市场切换 |
| 标的目录 | `/symbols` | 搜索缓存标的、查看市场列表 |
| 显示配置 | `/get_cl_config/<market>/<code>` | 保存基础图元显示选项 |
| 系统设置 | `/setting` | 行情请求网络代理 |
| 任务状态 | `/jobs` | 已注册任务及执行状态；默认不运行选股任务 |

主图右侧先显示当前标的、K 线/笔/线段/中枢数量和图层开关。中枢区间表可展开核对编号、价格上下界和状态。下面是自选、标的检索和板块联动。手工画线与自动结构分别管理，切换或更新自动结构不会把它们写入用户画线组。

自选分组支持不同市场混合存放，显示真实行情快照和涨跌幅。没有可用报价时显示缺失状态，不用零涨跌幅代替缺失数据。个股代码查询不会默认展开整个市场目录。

## 结构计算范围

1. 读取所选市场、标的和周期的 K 线，核对时区、闭合时间、复权口径与最小价格单位。
2. 处理包含关系，识别分型、笔，再按特征序列构造线段。
3. 使用本周期线段计算中枢。进入、三段核心与独立离开至少构成五个物理角色；核心区间由三段交集确定，进入和离开不混入核心矩形。
4. 已确认的外部离开后，首次反向回试严格位于核心区间之外才确认结束。恰好触边不构成三类确认。
5. 对返回核心的后续线段保留中枢延伸状态。未满足完整条件的候选框不画成正式中枢。

每个图表只显示当前周期：1m 用 1m K 线，5m 用 5m K 线，30m 用 30m K 线。当前版本不做 1m→5m→30m 递归中枢升级，也不分析多个走势结合律方案。中枢结束的内部边界判断不等于恢复了独立的买卖点信号产品。

代码使用固定生产规则。价格采用整数最小单位比较，避免浮点误差把触边误认为脱离；时间、价格基准与实体编号随结构传输。实际划分仍应结合图表核对，测试通过不代表证明了每个市场的全部历史划分。

## 数据与性能

首次打开时先提供 K 线和基础指标，结构计算在后台补齐；前端轮询等待同一份构建结果。相同标的、周期和数据口径共享计算任务，避免重复排队。

内存和磁盘缓存均绑定源代码、数据源、价格基准及周期。计算代码变化后使用新身份，旧的走势/混合结构缓存不会作为当前结果显示。相同已闭合数据复用结构实例，追加数据才走增量更新；历史修订或复权口径变化会重建实例。

QMT 优先核对本地历史覆盖，完整时复用；缺口按原数据源逻辑补取。美国分钟线保留开盘/收盘标签约定，图形与 K 线使用统一坐标。网络和供应商下载耗时仍取决于外部数据服务。

## 运行与检查

默认入口为 `windows_run.bat`，调用 `ops/restart_web.ps1`。重启先检查环境、版本和配置，再替换本项目 Web 进程；完成后检查就绪状态。脚本不再接收全量选股或模拟范围开关。

- `/livez`：进程是否存活。
- `/healthz`：轻量运行状态。
- `/readyz?market=a`：市场元数据、标的目录、行情和运行组件是否就绪。
- `ops/verify_deploy.ps1`：校验当前进程及源代码身份。
- `ops/watch_web.ps1`：Web 进程守护。外部行情暂不可用不会触发反复重启。
- `ops/manage_qmt_runtime.ps1`：单独管理 QMT 客户端。

不需要手工删除缓存来切换算法版本。图表空白时先看网络历史响应和健康接口，确认行情源可用，再检查图表加载状态；不要启动已删除的构建脚本。
