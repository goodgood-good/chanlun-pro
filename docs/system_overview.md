# 当前系统功能说明

当前正式接盘图按显示的 K 线周期分别处理原始行情、笔、线段和本周期中枢。图表不再递归拼接走势类型，也不使用旧的走势类型、背驰和跨级别点位结果。多图布局、个人显示偏好、TradingView 指标和手动画线仍可保存。

保存图表布局时，将当前时间轴柱宽和左右偏移写入布局的原生timeScale字段；恢复有效保存视图后不再自动拉宽默认范围。相同标的、周期沿用保存的价格轴状态。选股图表默认读取相同账户的分屏和次要面板周期，并加载对应市场、面板保存的指标布局；主图定位当前候选及其周期。跨标的或周期复用布局时保留时间缩放及指标，价格轴重新适配数据。选股链接的临时分屏、周期不写回解盘页默认偏好。自选行情列表显示价格和涨跌幅，上涨红色、下跌绿色、零涨跌及缺失值为中性色，不显示接收时间。

左侧“画图”区域在“画线、画框”按钮上方提供“手绘周期”下拉框。1m图可选1m、5m、30m，5m图可选5m、30m，30m图可选30m；切换图表周期后默认选择当前周期。先选择所属周期再画图，颜色和新图形的周期归属使用该选项。例如在1m图选择30m后画框，该框按30m保存，能在1m、5m、30m中显示。改变选项不修改已经画出的图形。

周期选择过程中保持下拉框焦点，行情刷新不会重设正在操作的选项。失焦、点击控件外部、切换周期重建控件及销毁图表时，会撤销临时焦点保护并恢复原生工具栏行为。

手绘图形按所属周期分级显示：1m图显示1m、5m、30m绘图，5m图显示5m、30m绘图，30m图只显示30m绘图。这三种周期共用完整的手绘保存状态，由图表库控制可见性；隐藏的图形仍被保存。在低周期编辑高周期图形不会改变其所属周期，删除当前可见图形也不会删除其他隐藏图形。周期之间切换无需重载同一份手绘状态，因此尚未发出的保存不会被旧缓存覆盖。

保存请求在排队前记录原标的、周期和明确的手绘身份，不使用切换后的图表身份写回；同一保存位置的请求合并为最新状态，不同保存位置的请求分别保留。自动结构在异步确认身份后也会从待保存快照中排除。旧共享或独立周期记录首次读取时按已有创建周期合并，保留原记录；缺少创建周期的旧共享图形维持共享可见性。新的保存记录优先，删除全部绘图后不会重新导入旧副本。账户、布局和图表位置的存储隔离沿用现有边界。

## 买卖点提醒

一、二、三类买卖点是用户指定的本周期程序规则，并在界面显示为已确认的正式提醒；这一身份不等于已经完成全部缠论走势类型的原文认证。

当前采用的操作口径是：每个 K 线周期以该周期已经确认、首尾相接的线段作为分析次级成员。快照的 `native_member_policy` 记录来源周期、线段成员口径及完整递归类型尚未证明的边界。第57课第79—103行给出按最小分析级别观察线段的方法；第65课第622—643行区分这种操作性处理与严格递归意义。原文出处分别为 `D:/缠论/chanlun_lesson_corpus/L057_当下图解分析再示范(2007-05-31223544).md`、`D:/缠论/chanlun_lesson_corpus/L065_再说说分型、笔、线段(2007-07-16221416).md`。采用本周期线段作为成员是当前用户选择的程序规则。

| 类型 | 本周期程序判定 |
| --- | --- |
| 一类 | 至少两个前后严格分离的本周期中枢构成同向背景；后一中枢完成离开及首次回试后，完整三线段离开腿创出该方向的新价格极值，且相对后一中枢的实际进入腿，原始 MACD HTF 同向柱面积缩小。 |
| 二类 | 从一类点真实价格极值所在段起，检查紧接的反向线段及首次同向回试；均须已锁定、首尾相接，且回试不越过一类点极值。首次回试可以位于完整一类比较组合内部，二类点的可知与确认时刻不得早于其父一类点可被识别的时刻。 |
| 三类 | 已成立中枢独立离开后，紧接的第一次反向返回线段保持在中枢核心相应一侧。 |

信号使用线段和中枢的来源 ID、真实价格极值、确认时间以及价格基准生成稳定身份。筛选发布前，程序会独立重算完整输入，并在信号首次可知的 K 线前缀重放，防止使用后来的数据回填。价格越过失效边界、同周期后续反向点已经确认，或点位结构锚定段紧接的反向线段已确认完成时，旧信号退出当前提醒窗口。一类点对应的二类点已有有效确认时，一类点也退出当前候选；二类点后来退出不恢复父一类点。后继线段尚在形成时不作为完成依据；历史图表标记保持其原有确认身份。

反向点的价格拐点和可知时刻均须晚于原点，避免将早已可知的内部反向点倒写成后续结束条件。原文第45课第37—49行讨论操作级别的后续卖点和持股、持币转换，出处为 `D:/缠论/chanlun_lesson_corpus/L045_持股与持币,两种最基本的操作。(2007-04-12.md`；这里按用户采用的本周期分析口径管理提醒窗口，是程序策略推导，并未重新定义历史买卖点。

筛选涨跌幅以快照的价格精度将最新收盘价对齐到整数 tick，再用十进制计算比例；恰好达到所设上限仍保留，超过上限一个实际价格 tick 时按条件排除。冻结结果校验同时检查整个中枢的进入、核心、延伸、离返来源、价格交集及时间链。单条行情记录的全部候选验证通过后才发布，结束提醒的原因保留在筛选诊断中。

三买选股默认只接纳已核验的上涨操作段首中枢，确认点与未确认预警使用同一规则。2026-10-13修正本周期结果分支曾绕过筛选偏好的问题，并停止将图表点位中的局部 `center_ordinal` 计数当作首中枢证明。读取端按照该点自身可知时刻的冻结中枢和已确认离开事实生成 `center_sequence`；后来的中枢不能回写较早点位的序号。重叠、重新划分或历史缺失均不能把计数重置为1。当前程序只有在已核验的反向离开与严格分离的反向中枢对提供重新起算依据后，才允许确认新的首中枢；起点、来源或中间离开事实不足时明确标记待核验，按“仅首中枢”条件排除。这是现有本周期线段成员框架内的保守筛选实现，不是完整递归走势类型已经成立的证明。

依据为本机原文 `D:/缠论/chanlun_lesson_corpus/L091_走势结构的两重表里关系1(2007-12-17214015).md` 第1045—1051行及 `D:/缠论/chanlun_lesson_corpus/L029_转折的力度与级别(2007-02-09150808).md` 第2131—2137行对首中枢后介入的讨论；中枢延伸、新生和扩张的区别见 `D:/缠论/chanlun_lesson_corpus/L020_缠中说禅走势中枢级别扩张及第三类买卖点.md` 第148—163行。“只选首中枢”是选股偏好，不把后续中枢的三买改判为无效图表点位。历史结果保留原始点位用于复核，界面的“仅首中枢”按独立序列证明筛选。实时监听同样检查该证明；旧队列缺少当前证明时先复核，不沿用旧序号发送。规则版本和结果缓存同步失效，已完成批次可直接重读冻结证据，无须重新下载全市场K线。

## 周期和通知

选股页分别展示5m结构确认和5m交易确认数量。状态筛选中的“本周期结构已确认”可以查看5m已经确认但1m仍待确认的点位；“交易／短差已确认”继续要求5m通过对应区间的1m确认，1m短差则按自身状态判断。“条件待齐”同时包含主周期尚在形成和主周期已确认但小周期未通过的情况，不能将这些候选统一称为未确认结构。该展示区分不放宽选股发布或通知条件。

2026-10-14选股工作台将计算范围与显示条件分开。正常扫描计算六类点；30m背景、5m交易及按需1m确认固定启用，全范围1m短差为额外开关。范围支持A股全市场、全部自选分组、指定分组及含市场的指定代码。ST／退市名称条件在股票池合并后统一作用于A股股票，以行情目录名称核对；缺少名称依据的标的报告数据问题，不能用自选别名绕过。诊断和导出保存排除数量与代码，人工关注和持仓监听继续独立处理。

主视图只保留“选股结果”和“历史结构”，各自保存显示条件；5m和1m也独立保存适用条件。历史只展示已经保存的一买、一卖退出结构，不提供没有事实依据的交易状态、背景或价格距离过滤。自选分组是独立开图入口，切组与开图不清除筛选。上批结果在独立折叠区显示批次、截止、数量和分页，只读且不计本轮，完成重算后自动收起；导出以`previous_candidates`单独保存上批记录。

显示时间明确区分主结构确认、两级交易条件齐备及价格拐点。日期年龄按各市场交易日计算，最近N日包括截止日，缺失时间不能当作当天。按最近时间排序使用所选时钟，价格距离为未取整的绝对值`|截止收盘/拐点价−1|×100%`，未知置后。计算中的“顺向涨跌幅上限”仍是候选覆盖条件，与显示的绝对距离分别命名；按交易时间查看也不能召回已在主结构时效窗口之外的点。计算默认主结构最近5个交易日、拐点回看20个交易日、顺向涨跌幅上限10%，扩大覆盖需要重新计算。

30m背景采用计算器同一中枢方向口径，1m短差与5m交易都区分顺势、逆势、震荡、待核验。六类周期联动仅作为高级分析维度，不能代替5m交易必须通过的1m区间确认。联动优先读取同批次冻结的1m／5m／30m输入，绑定文件摘要、截止、价格基准与来源版本；冻结证明损坏时不替换为无关实时缓存。待核验分别显示证据缺失、截止不符、价格基准或收盘不一致、结构不足等原因；已经检查但依据不足不会无限显示仍在读取。兼容当前`native-strength-v2`计算模式。

QMT收盘时间标签本身不能证明缓存末根K线已完整，正成交量也可能是未结束桶的残留。A股1m／5m／30m输入首次使用时刷新截止日的原生小窗口，并核对实际OHLCV；30m沿用行情源5m下载基底和30m读取契约。全范围扫描按最多100只批量准备，进程可取消且停滞会回退到标的级核验，不下载整个历史。证明绑定实际内容、价格基准、截止及来源实现；相同内容复用，内容改变或证明损坏重新检查。历史前缀保留，复权变化时重新读取同基准完整历史；失败标记“已收盘输入尚未核验”，不放宽跨周期同价要求。离线性能回放工具显式关闭网络核验，只处理既有输入，不作为生产发布入口。

已收盘窗口准备使用本机SDK的同步原生区间请求，每只完成后释放共享下载通道并更新进度。全市场实测发现异步批量接口偶尔永不返回完成回调，故不将该接口用于闭合证明；这也避免其占住共享通道后拖累实时监听。分块只负责组织请求，正式证明仍绑定随后读出的实际K线内容。

午间自动选股优先处理5m、30m，持续运行到本轮所有标的周期处理完毕，不设置20分钟或12:55的整轮停止时间。并发仍服从共享计算预算和内存保护，用户可手动取消；启动失败和计算失败沿用有限重试次数。因旧午间时限停止的当前批次，可经校验后接着处理未提交周期：保留原始标的名单、算法版本、行情截止和已提交结果，不将下午行情混入中午批次。续算前保存检查点，界面显示保留进度，完成后同步更新当日午间状态。

通知终态额外保存逐条复核原因、原始市场时钟和事件身份，区分市场事件过期、偏好关闭、范围变化、信号退出、状态替代、身份核验和首中枢条件不符。历史泛化错误记录不做猜测性回填。恢复线程使用统一的短暂读取失败重试机制，避免一次Windows文件占用直接造成30秒等待。

混合通知批次在部分发送、部分等待或拆分时，也保存被排除成员的身份、原始时钟和具体原因；后续重试、过期与服务重启不会覆盖此前记录。发送前、校验中和实际请求前的过期，以及最后一刻合并重复提醒，均记录到相应回执。任务面板区分整批发送状态与部分成员被排除。队列每小时维护已终止历史，保留30天回执和90天去重标记；维护不依赖再次向通知平台发出请求，不删除仍在处理的消息及其载荷。

通知平台返回成功后，先把该次成功回执同步保存到数据库旁的独立主备文件，再提交SQLite发送状态、时间和去重标记。成功回执已经保存时，数据库暂不可写或提交前进程退出，下一次发送前会先核对回执摘要、队列身份、消息身份和发送批次序号，补写本地记录并退役主备文件，不再调用平台发送同一条消息；关闭通知时也可完成这项本地恢复。文件清理失败可幂等重试，一个有效副本可恢复另一个副本。临时写入失败时，当前进程保留已接收状态并继续尝试落盘；若另一发送进程已完成恢复，旧实例不重新发布过时回执。没有观察到成功响应的在途请求仍沿用原有重试策略，不据请求开始时间推断已送达。

部署预检使用正常进程优先级，默认等待上限60秒，仍在全部检查通过后才停止旧服务。网页和调度进程显式使用正常优先级，结构计算子进程继续使用较低优先级，避免全市场计算拖住页面、行情初始化和调度响应。
