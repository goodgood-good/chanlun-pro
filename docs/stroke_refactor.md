构建与状态如何联动

`StrokeResolver` 按时间推进物理分型。异类候选首先通过旧笔距离、两端价格、完整区间核验，再排除跨过合格反向结构的连接；原相邻关系仍合格时沿用，否则在合格候选中处理同类极值和先后。短促转折不会因不能独立成笔而删除其 K 线价格，它本身仍可成为后续连接的起点。区间核验缺少完整证据时不放行。

输出与证据分别为：

| 字段 | 含义 |
| --- | --- |
| `bis` | 当前选出的合格旧笔，包含末笔。 |
| `qualification_evidence` | 每条连接的两端，以及终点首次物理可见时间、连接实际选入时间、导致选入的分型。 |
| `completion_evidence` | 当前划分中，前一笔被下一条合格笔承接的首次证据；未改变的连接保留首次见证。 |
| `confirmed_bis` / `BI.locked_at` | 当前已有上述承接证据的笔及见证时刻。 |
| `pending_bis` / `pending_bi` | 当前最后一条合格笔；继续接受端点延伸和取舍。无合格连接时为空。 |
| `selection_revisions` | 端点重选的旧末端、新末端、改动起始位置、当时见证时间，以及是否影响已有承接状态。 |

`FX.done` 只表示三 K 分型已形成，不能随笔端点取舍任意改成假。`fractal_visible_at`、`selected_at`、`locked_at` 分别表示分型可见、连接选入、获得下一笔承接，时间不能相互冒用。后续才选入一个早已出现的分型时，不能倒填选入时间；批量计算通过重放右肩来源 K 线，复现逐根计算的首次证据。

**程序的 `confirmed` / `locked` 是当前划分中的承接状态，这是状态接口的工程含义，不声称第 69 课逐字定义了这一通用、永久不可改的判据。** 第 69 课的完成限制与第 77 课特定证明没有被用来补造一个“所有可能未来都不可修改”的定理。当前取舍变化可能影响先前已有承接证据的笔，必须显式记录并重算；读取旧历史快照的调用方不能把这组字段理解成永不修订的承诺。

端点或资格、承接证据改变时，`BiCalculator` 重建相应 BI 对象，使 `XdCalculator` 重算依赖的线段。`CL` 同时清除旧结构 memo、中枢前缀缓存及来源确认登记；登记器保留品种、周期和价格口径约束。正常增加下一笔时，未变的前缀对象、首次见证和登记器沿用。缓存 schema 已升级为 `chanlun-analysis-cl-v7`，旧的 v4/v5/v6 状态不能直接恢复。

此前讨论的 C<A、B>P 如何处理

设 P 顶 → A 底 → B 顶 → C 底，C 是不够旧笔间隔的短促底，且 C<A、B>P。必须按每条拟连接各自的时间区间判断，不能把不同候选的失败混在一起。

| 拟连接或动作 | 核验结论 |
| --- | --- |
| A→B | C 在 B 之后，不在 A→B 内部；C<A 不会据此否定 A→B 的内部极值。 |
| B→C | 若距离不足，不构成旧笔。 |
| A→后续 D | 若内部含有更低的 C，A 不是全笔最低，不能把 A→B 延伸为 A→D。 |
| P→C | 内部 B>P，P 不是全笔最高，不能直接延长前一下降笔。 |
| 忽略 C 的价格 | 不允许。它不被选为当前端点，价格仍在区间里。 |
| 回到更早 Q 或 S | 必须重新核验整个拟连接及相邻结构，不能凭上述两个不等式决定固定回退几笔。 |

这些结论是第 62、66、69、77 课上述出处的联合推导，原文并没有以这组字母列出程序分支。回归包含完整 OHLC 及上下镜像。一个已核验的续接样本在 B→C 过近后，最终选择 P1→A5→B9→E19，保留前面的合格反向结构；不会因 B>P 强行合并成 P→C。

另一个短促双向越界样本的中心和端点价格为 P1=20、A5=8、B9=22、C11=6、D13=24、E17=4。P→A、A→B 合格，B→C、C→D 过近，而 A→D、P→C 又违反区间极值。当前选择器在 D→E 合格后重选观察起点，并记录对旧选择的修订。**这是对未能接续的当前选择采用的确定性处理，不是原文明确要求“整段只剩 D→E”的证明，也不授权任意抹除历史笔。** 该案例保存在 [端点回归](D:/project/chanlun-pro/tests/core/test_stroke_endpoint_candidates.py)，修订通过状态和依赖缓存传播。

相等极值的例子为 P1 顶 20、A5 底 6、B8 顶 14、C11 底 6、D15 顶 12。A→D 内部的 B 更高，所以不能仅凭 A 比 C 早就使用 A→D。当前在 D 可见时选入 P→C→D；P→C 的端点分型在 C 右肩时已可见，但连接选入及承接时间都是 D 的见证时间。这个案例验证“优先较早”不能覆盖整笔极值要求。
