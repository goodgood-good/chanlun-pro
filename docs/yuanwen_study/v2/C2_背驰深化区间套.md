## 第25课 吻，MACD、背驰、中枢（行14832-15864）

> 既有覆盖：C5.12（三判据）、C5.15（MACD失效场景）、C5.16（双次拉回）、C5.17（0轴中枢级别下界）。以下为增量/矛盾。

- **C2.1** 乖离极限判据的适用前提与面积例外：「这种判断的前提是 1 分钟的急促上升，其他情况下，必须配合黄白线的走势来用」；600779 例「虽然其形成的面积大于前面的，但这种两次冲击乖离极限而不能突破，就意味着……要歇歇了」（行14840）。即急拉场景**柱高极限优先于面积判据**（面积更大也判走弱）。【缺失】系统 macd_ld 只比面积/高度，无「急拉模式切换为柱高极限+多次冲击不过」的特例。影响：低（超短场景）。
- **C2.2** 第一段连续涨停的节奏规则：「如果这种连续涨停是出现在第一段的上涨中，即使打开涨停后，震荡结束，形成一定级别的中枢后，往往还有新一段的上涨，必须在大级别上形成背驰才会构成真正的调整」（行14933）。操作含义：超短卖点意义不大，「关键是要抓住大级别的调整，不参与其中」。【缺失】影响：低-中（A股涨停场景的持仓节奏）。
- **C2.3** 小级别背驰权重由大级别 MACD 阶段调制：「日线上在上涨的中段刚开始……MACD 刚创新高，红柱子伸长力度强劲，这时候 5 分钟即使出现背驰，其下跌力度显然有限，所以只能打点短差，甚至可以不管。而在日线走势的最后阶段，特别是上涨的延伸阶段，一个 1 分钟的背驰足以引发暴跌，所以这一点必须多级别地综合来考察，绝对不能一看背驰就抛」（行14939-14940）。与 C5.36（小转大高发位=趋势赶顶/赶底）互为正反面：**同一小级别背驰信号的处置由大级别所处阶段（中段刚启动 vs 延伸末端）决定**。【缺失】系统卖点处理只有 original_layered 的「大级别 up 时小级别卖点只减活动层」，无「大级别主升中段忽略小背驰 / 延伸末端小背驰升权」的阶段判别。影响：**高**（直接对应卖点误卖/漏卖两类成本）。
- **C2.4** 主升段（突破第一中枢段）的结束判据=次级别背驰：「其后突破该中枢，MACD 的黄白线也快速拉起，这往往是最有力度的一段，一切的走势延伸等等，以及 MACD 绕来绕去的所谓指标钝化都经常出现在这一段，这段一般在一个次级别的背驰中结束」（行14940）。本级别 MACD 在主升段必钝化（黄白线未回0轴，按 C5.10 本级别背驰不存在），段结束只能用**次级别背驰**判。【确认+细化】与 C5.10 一致；系统 macd_htf（高一档周期判背驰）方向恰好相反——原文是「向下找次级别」而非「向上借高档」。影响：中（佐证 macd_htf 工程近似偏离原文方向）。
- **C2.5**【回复】操作不等确认总纲：「操作上，一定不能等什么确认，而是有卖点就卖，有买点就买，当然是根据相应的级别。即使你是中线持有，5 分钟、30 分钟背驰，也可以先卖部分出去，下来再回补」（行15063-15066）；同课「冲高只要没力，也就是短线背驰，就出来，回试不破就回补，而不是看最后的结果，如果结果破了，那时候再操作，是不是有点太晚？」（行15226）。【冲突】影响：**高**——系统 L1 信号靠摆动腿钉死（170-519 bar 滞后）本质是「等确认」，正是原文明令禁止的；为区间套候选机制（6b 研究 §3）再添两处原文行号依据。
- **C2.6**【回复】机动资金配比与买卖级别不对称：「这种（机动）资金应该占仓位的 1/4 到 1/3，走势特别不好时甚至应该提高到 1/2。在牛市里，即使是中期调整，也没必要完全空仓」（行15091）；「1 分钟背驰就把机动的资金撤出来……这部分资金绝对不能追高，而下次的买点，就要看 30 分钟等的调整情况，要综合判断，不能光一味用 1 分钟」（行15091）；「要集中兵力，而且要有机动的资金」（行15372）；资金大者只能部分短差、小资金可全仓进出（行15227、15066）。**卖出触发级别(1m)与回补判断级别(30m)不对称**。【缺失】系统 core/swing/scalp 分层无「机动仓位 1/4-1/3、恶劣市况 1/2」的显式配比，scalp 回补无大级别综合判断。影响：中（资金管理维度，基线已列为空白）。
- **C2.7**【回复】有效跌破的精确定义：「（有效跌破）就是次级别下去，次级别反拉不能重新上来。这和百分比无关」（行15309）。【冲突】影响：**高**——系统结构失效边界（3buy 破 ZG 当根判定次 bar 退出）用瞬时价格口径；6b 研究 §5.1.3 留的开放问题（插针洗出 vs 确认延迟）在此有原文解：失效=次级别走势级别事件（次级别下去+次级别反拉不能上来），非任意可见低点、亦非收盘价工程口径。
- **C2.8**【回复】中枢扩展确认的回拉级别条件：「第一次很低级别的回抽，只要不跌回中枢里面，而是触及围绕中枢震荡的外围高点……还不能肯定就一定会构成更大级别的中枢。……如果第一次的回拉只是 5 分钟级别的，那很可能只是上升途中的小级别回拉，只有当次级别的（对日线=30 分钟级别）回拉触及，才算是构成更大级别的中枢」（行15239-15240）；配套「回试如果是两次的，只要下一次不跌破这个位置，中枢的脱离得到确认」（行15142）。【缺失/待查 topic2】kuozhan 扩展判定是否校验「回拉段级别≥次级别」未与原文对齐；触及 GG/DD 不足以定扩展。影响：中。
- **C2.9**【回复】操作级别-时间名义表：「中线=周线级别，日线算中短线，月线以上算长线，30 分钟算短线，5 分钟只能算超短线，而 1 分钟只多 T+0 有意义」（行15384）。【缺失】低（报告/仓位语义的命名对照）。
- **C2.10**【回复】三类买点成立本身需要次次级别确认：「第三类买点一定要等到**次次级别的背驰或双次回拉**确认」（行15580，答「日线三类买点没等 5 分钟线背驰」之问；行15583-15587 加注：日 3 买=30 分走势离开+回抽，回试无论 3/5/9 段 5 分构成「最后都要看 5 分图背驰」——注意加注为后人注，原文判据是行15580 一句）。与 C2.5「不等确认」**不矛盾**：C2.5 指买卖点按定义成立后即操作；本条是 3 买回试结束的**定义性判定**=次次级别背驰或 MACD 双次回拉（C5.16 机制移用）。【冲突】影响：**高**——系统 3buy=「retest.end>=ZG」几何口径即发信号，无次次级别背驰/双次回拉确认；与 topic2 C2.16（精确买点=次级别一买）同源，增量为「MACD 双次回拉」是原文认可的**替代确认通道**。
- **C2.11**【回复】盘整背驰同样要求 0 轴回拉结构:「000915 现在还在一个盘整里，不符合趋势两段比较的背驰，至于盘整中的背驰，现在也没有，因为这种刚上 0 轴的，根本就谈不上背驰，背驰是要上 0 轴后有一次大拉升，然后回抽 0 轴，再拉升，才会有背驰的」（行15672-15674）。C5.10 的 0 轴必要条件**对盘整背驰同样成立**。【缺失】影响：中——系统盘整背驰（macd_ld 面积比较）未检查「黄白线回抽 0 轴」前提，刚上 0 轴段会误报。
- **C2.12**【回复】买点价格次序与最低级别三买稀缺：「第三类买点在 1 分钟里是很难有的，因为 1 分钟就是最低的，第三类很难找到。第一类买点当然比第二类低，二比三低，卖点反过来」；并给出 2 买 MACD 特征「双回抽 0 轴站稳」（行15752-15753）。【缺失】影响：低-中——「1买<2买<3买（价格），卖点反向」可作系统级断言/数据质检；最低递归层产 3buy 需谨慎（系统以笔为 L0 次级别绕开了图级限制，应标注为工程扩展）。
- 确认项（不展开）：盘整背驰不必大跌、可成三买（行14937，=C5.18）；趋势背驰至少回 B 段（行14939，=C5.19）；「刚从 0 轴上来，不存在背驰的问题」（行15021【回复】，=C5.10 反例）；「不是柱子缩短就是背驰……黄白线有回拉 0 轴吗」（行15280、15346-15352【回复】，=C5.10/C5.12）；「用 MACD 判断背驰首先要有黄白线对 0 轴的回拉……在该级别就不存在什么背驰，其他级别要相应去看」（行15863【回复】，=C5.10 再证）；连接两同向趋势的盘整中枢级别更高（行15119【回复】，=C5.32）；下跌/盘整判定一律以中枢角度（行15261【回复】）；上升中枢必下上下起（行15361【回复】，=C5.9）；中线持有也按短线买卖点弄差价降成本（行15525、15540【回复】，=C2.5/C2.6 同旨）。

## 第27课 盘整背驰与历史性底部（行16984-18440）

> 既有覆盖：C5.2/20/21/22/25/27/28/38/39/40/46、C5.23；6b 研究 §1 已引 27 课区间套核心段。以下为增量/矛盾。

- **C2.13** 盘整背驰的位置调制：「小级别的盘整背驰，意义都不太大，而且必须结合其位置。如果是高位，那风险就更大了，往往是刀口舔血的活动；但如果是低位，那意义就不同了」（行16998）。本质定义：第一中枢即背驰=「企图脱离中枢的运动，由于力度有限，被阻止而回到中枢里」（行16996）。【缺失】影响：中——系统对盘整背驰类信号（L0 盘整 1buy/bcs）无「高位/低位」位置权重；与 C2.3 同族（大级别位置调制小级别信号处置）。
- **C2.14** 区间套下推深度由资金规模决定：「光看季度线是不可能找到精确的买点的，但对大资金，这已经足够了，因为大资金的建仓本来就是可以越跌越买，只要知道其后是一个季度级别的行情就可以了。而对于小资金来说……精确的买点可以继续从月线、周线、日线、甚至 30 分钟一直找下去」（行17049-17050）；「1 分钟的背驰段……对大资金，基本没什么用处」（行17070）。【缺失】影响：中——补全 C5.46「级差一档」之外的第二维度：**下推深度=f(资金规模)**，引擎的 nest 深度不应一刀切；大资金语义=背驰段成立即可分批建仓（「季度线跌破 3.2 元后，这个背驰的成立已经是确认了」行17050——创新低当下即确认进入背驰判定域，候选机制原文又一据）。
- **C2.15**【回复】买点「正形成中」可部分介入：「谁告诉你每天都一定有买点的？在强烈的趋势中，1 分钟的买点有时候 2、3 天才有一个。不过 5 分钟的买点正形成中，对于大资金以及好股票，其实今天就可以开始部分介入了」（行17206、17698）。【缺失】影响：**高**——「候选态（买点形成中）+部分仓位」是 6b 研究 §3 候选介入机制的直接原文依据（比 C5.41 更显式的操作授权）；系统现状只在「信号可见」后满标准仓介入，无候选态部分介入。
- **C2.16** 最低级别（无次级别图）的退化判定与卖出纪律：「这卖点要看次级别的，而 1 分钟下面看不到，所以一般来说，**3 波上去就可以走**」（行17230）；「注意，是涨的时候形成卖点，而不是跌下来再走。**宁愿卖早了，不要卖晚了**。特别是对冲」（行17234、17744）。【缺失】影响：中-高——①最低递归层背驰段结束=三波（三段）结构完成即离场（系统笔级无此退化规则）；②卖向时机纪律「宁早勿晚」与系统卖点确认滞后（跌下来才可见）方向相反，是卖向区间套（6b §5.2.4）的原文支撑。
- **C2.17** 次级别背驰的层级功能=把本级别 MACD 拉回 0 轴：「目前的走势很简单，就是等待一个 5 分钟的背弛把 30 分钟 MACD 拉回 0 轴。……今早的只算是宣告进入背弛段，精确的背弛点还要看 1 分钟级别的走势」（行17281-17283）。【缺失】影响：中——跨级别 MACD 状态联动（次级别背驰完成≈本级别 0 轴回拉完成）可作为「本级别背驰前提（C5.10）即将满足」的前瞻信号；同句再证「进入背驰段（状态）≠背驰点（事件）」两态分离。
- **C2.18** 背驰失败后的级别升级演化：5 分钟背驰若反弹不过关键位（2720），「就有在下面形成下跌的第二个中枢的可能……但即使这样，只会导致 30 分钟或 15 分钟回抽后制造一个比这次 5 分钟更大级别的背驰，那次的回拉，级别就更大了」（行17287-17288）。【缺失】影响：中——背驰兑现失败不是判据失效，而是「下一次背驰升一个级别、回拉更大」的演化分支；系统无此「背驰级别递进」的候选续期逻辑。
- **C2.19** 三类卖点后第一段的背驰降权：「从第二个中枢开始的一段，与从第一中枢开始的一段，力度上也没有特别的减少，所以这时候就是特别小心会产生第三个中枢。一般来说，**从第三类卖点下来的一段，除非力度特别弱，跌破中枢后马上拉回，否则都不会构成真正的背弛，也就是说相应的次级别背驰只造成一个下跌中枢**」（行17414，2007-02-06 作业答案）。【缺失】影响：**高**——三卖后顺势段中的次级别底背驰大概率只造一个新中枢（中继）而非反转，系统当前对该场景的 L0 1buy/bcs 不降权（NVDA 式「下跌中接飞刀」的原文反向判据）；例外条件明确=「力度特别弱+跌破中枢后马上拉回」。
