## 一、背驰定义与判定（趋势背驰 / MACD程式 / 比较段）

### 1.1 背驰的前提：必须先有趋势

- 「没有趋势，没有背驰，不是任何 a+A+b+B+c 形式的都有背驰的。当说 a+A+b+B+c 中有背驰时，首先要 a+A+b+B+c 是一个趋势。而一个趋势，就意味着 A、B 是同级别的中枢」（37课，行24432）。
- 若 A 级别比 B 大，则 a+A+b+B+c = a+A+（b+B+c），b、B、c 只是围绕大中枢 A 的小级别波动，「这样，是不存在背驰的，最多就是盘整背驰」（行24432）。
- 趋势对中枢数量的要求：「趋势，一定有至少两个同级别中枢，对于背驰来说，肯定不会发生在第一个中枢之后，肯定是至少是第二个中枢之后」（27课，行16993）。「第二个中枢后就产生背驰的情况，一般占了绝大多数的情况，特别在日线以上的级别，这种就几乎达到 90%以上」（行16993）；「一般 4、5 个中枢以后才出现背驰的，都相当罕见了」（行16993）；下跌「最多就是 3、4 个中枢，超过 4 个的极为罕见」（27课，行17443-17445）。
- 段数底线（回复区）：「一个趋势，有两个中枢，因此至少就有 6 段走势，然后加上前面低部回拉的第一段，最后冲刺的一段，还有连接两个中枢的一段，至少有 9 段走势」（24课回复，行14566-14568）。

### 1.2 比较的两段是什么：c 与 b 比（围绕**最后一个中枢**的前后两段同向走势），不是 c 与 a 比

三处互证：

1. **24课 A/B/C 段记号**：「用 MACD 判断背驰，首先要有两段同向的趋势。同向趋势之间一定有一个盘整或反向趋势连接，把这三段分别称为 A、B、C 段。显然，B 的中枢级别比 A、C 里的中枢级别都要大……A 段之前，一定是和 B 同级别或更大级别的一个中枢」（行14400）。即 24课的 A 段＝两中枢间的连接段（＝37课记号的小写 b），B 段＝最后一个中枢（＝大写 B），C 段＝最后冲刺段（＝小写 c）。背驰判定是「C 段……对应的 MACD 柱子面积……比 A 段对应的面积要小」——翻译成 37课记号即 **c 与 b 比**。
2. **61课直接表述**：「要比较力度，发现背驰，首先要搞清楚是哪两段比较，其实，只要是围绕一中枢的两段走势都可以比较力度。显然，对于 60-65 这个 1 分钟中枢，55-60 与 65 开始的一段之间就可以比较」（行33015）——围绕**同一个中枢**（趋势场合即最后一个中枢）的前、后两段。
3. **37课回复**：「通常提到背驰或盘整背驰，都指 a+A+b 这样的三段，其中 A 是一个本级中枢，a、b 是次级以下走势，b 与 a 比较是否背驰或盘整背驰」——缠师对此问法未予纠正，只补充「只要能比较力度，就可以用盘整背驰的方法。而背驰，必须在趋势中，因为背驰意味这一个趋势的结束，而盘整背驰不一定，可能还是同一个走势类型里」（行24554-24556）。

「背驰只与最后一个中枢有关」的字面表述原文未见【待核】，但 37课有近义表述：「对于最后一个中枢 B，背驰与盘整背驰有很多类似的地方，用多义性，可以把 b、c 当成 B 的次级波动。但多义性只是多角度……不能忘了 a+A+b+B+c 是趋势且 A、B 级别相同的角度」（行24432）。

### 1.3 背驰段 c 的成立条件（37课五条件，详见第三节）与力度判断标准

- 力度判断的工具序列：原文以 MACD 为「不绝对精确，但比较方便」的辅助（24课，行14391-14394）；「要精确地判断背驰与盘整背驰，还是要从中枢本身出发」（行14465）；「光用 MACD 辅助判断……只要能分清楚 A、B、C 三段，其准确率也应该在 90%以上。而配合上中枢，那是 100%绝对的」（行14468）。
- 27课作业图给出的非 MACD 力度口径：比较「MACD 上回来 0 轴后的下跌黄白线的斜率和速度」（行17414，括注为整理者所加，正文意为从第二、第三中枢出发的两段下跌力度对比）。
- 44课回复补充力度判断的边界：「创新高或新低才有背驰或盘整背驰的可能。未创新高的情况，其实可以按中枢震荡的方式去看，等于达不到上次震荡的力度……但和背驰不是同一样东西」（行27230）。

### 1.4 背驰的两大定理

- **缠中说禅背驰-买卖点定理**：「任一背驰都必然制造某级别的买卖点，任一级别的买卖点都必然源自某级别走势的背驰」（24课，行14396）。
- 「只要你看到某级别的背驰，必然意味着要有逆转。但逆转并不意味着永远的」——逆转幅度＝「重新出现新的次级别买卖点为止」（行14395、14388）。
- **缠中说禅背驰-转折定理**（29课，43课重引）：「某级别趋势的背驰将导致该趋势最后一个中枢的级别扩展、该级别更大级别的盘整或该级别以上级别的反趋势」（29课，行20077-20080；43课，行26508）。
- 回跌的底线：「趋势中产生的背驰，一定至少回跌到 B 段中，这就可以预先知道至少的跌幅」（24课，行14463、14683；25课，行14939）。

### 1.5 MACD 辅助判断的精确程式（24/25课）

**完整原文（标准程式）**：「用 MACD 判断背驰的前提是，A、B、C 段在一个大的趋势里，其中 A 之前已经有一个中枢，而 B 是这个大趋势的另一个中枢，这个中枢一般会把 MACD 的黄白线（也就是 DIFF 和 DEA）回拉到 0 轴附近。而 C 段的走势类型完成时对应的 MACD 柱子面积（向上的看红柱子，向下看绿柱子）比 A 段对应的面积要小，这时候就构成标准的背弛」（24课，行14401）。

分解为可执行条件：

| # | 条件 | 行号 |
|---|------|------|
| 1 | 前提：A、B、C 三段在一个大趋势里，A 之前已有一个中枢（即趋势的第一个中枢） | 14400-14401 |
| 2 | B（最后一个中枢）把黄白线（DIFF/DEA）回拉到 0 轴附近——**必要条件**：「黄白线没拉回 0 轴前是不会有背驰的」（27课回复，行17795）；「如果 B 段不是回抽 0 轴附近，就根本不满足条件，否则任意三段都可以用 MACD 判断背驰了，那不乱套了？」（27课回复，行18288） | 14401 |
| 3 | C 段完成时对应柱子面积（向上看红柱、向下看绿柱）< A 段对应面积 | 14401 |
| 4 | 价格必须创新高/新低（见 1.3、37课条件4；「三角形，没有新高，怎么会有背驰？」24课回复，行14675） | 24437、14675 |

**三判据版本（25课）**：标准两中枢上涨的 MACD 全程形态——第一段黄白线从 0 轴下上穿、0 轴上方停留形成第一个中枢与第二类买点；突破后黄白线快速拉起（最有力一段，走势延伸与「指标钝化」多发生于此），在一个次级别背驰中结束；进入第二个中枢，黄白线逐步回到 0 轴附近；最后再突破，「但这次，黄白线不能创新高，或者柱子的面积或者伸长的高度能不能突破新高（注：1黄白线 2柱子面积 3柱子高度），出现背驰，这就结束了这一个两个中枢的上涨过程」（25课，行14940）。

**或条件口径（27课）**：万科季线「MACD 明显出现标准的背弛形态：回抽 0 轴的黄白线再次下跌不创新低，而且柱子的面积是明显小于第 1 段的，一般来说，只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准了」（行17048-17049）。

**实操技巧**：

- 面积乘 2 法：「看 MACD 柱子的面积不需要全出来，一般柱子伸长的力度变慢时，把已经出现的面积乘 2，就可以当成是该段的面积。所以，实际操作中根本不用回跌后才发现背驰」（24课，行14407）。
- 分段累加法：C 段内部多波时把各红柱面积加总与 A 段比较——上证5分钟例「把三个红柱子的面积加起来，也没有 A 段两个红柱子面积和大，显然背驰了」（24课，行14453）。
- C 段中途不能提前判背驰的两个理由：第一波没创新高不构成背驰；C 段还没形成中枢时「根据走势必完美，这 C 段肯定没完」（行14449-14450）。
- MACD 失效场景（25课）：①急拉/快速走势在 1 分钟图上反应也太慢，改用「MACD 柱子伸长的乖离极限」（两次、三次冲极限高度不能突破即歇），前提是 1 分钟急促上升（行14837-14840）；②连续一字涨停时 MACD 出现正弦波样失真，「不能用背弛来看，最简单，就是用 1 分钟的中枢来看，只要中枢不断上移，就可以不管」，配合用 30 分钟长周期 MACD 的红柱低点渐低触 0 轴作警告信号（行14884-14885）。
- 综合性要求：「各位一定要把 MACD 判断背驰的几个条件综合起来，不能光看柱子就完事……就是因为柱子经常无效，所以才需要综合性的背驰概念」（25课，行15352）；「背驰需要多少个条件？光柱子缩短就背驰？前面的黄白线有回拉 0 轴吗？」（行15346）。

## 二、盘整背驰（定义＋用途＋判据）

### 2.1 定义与本质区别

- 命名：「盘整中，利用类似背驰的判断方法，也可以有很好的效果。这种盘整中的类似背驰方法的应用，称为盘整背弛判断」（24课，行14417-14418）。默认口径：「一般不特别声明的，背驰都指最标准的趋势中形成的背驰」（行14417）。
- 与趋势背驰的本质区别（37课回复）：「背驰，必须在趋势中，因为背驰意味这一个趋势的结束，而盘整背驰不一定，可能还是同一个走势类型里」（行24555-24556）。
- 第一个中枢处的「背驰」降格：「如果在第一个中枢就出现背驰，那不会是真正意义上的背驰，只能算是盘整背驰，其真正的技术含义，其实就是一个企图脱离中枢的运动，由于力度有限，被阻止而出现回到中枢里」（27课，行16996）。
- 比较段的放宽：「这里是把第一、三段看成两个走势类型之间的比较，这和趋势背驰里的情况有点不同，这两个走势类型是否一定是趋势，都问题不大，两个盘整在盘整背驰中也是可以比较力度的」（27课，行17000）；「只要能比较力度，就可以用盘整背驰的方法」（37课，行24555）。
- 前提同样要求创新高/新低：「创新高或新低才有背驰或盘整背驰的可能」（44课回复，行27230）。

### 2.2 盘整背驰的三种情况（24课，向上为例）

「盘整中往上的情况为例子……如果 C 段不破中枢，一旦出现 MACD 柱子的 C 段面积小于 A 段面积，其后必定有回跌。比较复杂的是如果 C 段上破中枢，但 MACD 柱子的面积小于 A 段的，这时候的原则是先出来，其后有两种情况，如果回跌不重新跌回，就在次级别的第一类买点回补，刚好这反而构成该级别的第三类买点，反之就继续该盘整」（行14420）。归纳：

1. C 不破中枢 + C面积 < A面积 → 必回跌（短差卖点）；
2. C 上破中枢 + 面积小 → 先出来；回跌**不**重新跌回中枢 → 在次级别第一类买点回补＝**该级别第三类买点**（万科15分钟例，行14461-14462，image209/206）；
3. C 上破中枢 + 面积小 → 先出来；回跌跌回中枢 → 继续盘整（上证5分钟例，行14453）。

缠师收尾强调：「盘整背驰里的三种情况，特别是形成第三类买点的情况，一定要搞清楚。注意，盘整背驰出来，并不一定都要大幅下跌，否则怎么会有第三类买点构成的情况」（行14683；25课重申，行14933-14937）。

### 2.3 用于什么买卖点

- 「多数的第二、三类买点，其实都是由盘整背驰构成的，而第一类买点，多数由趋势的背驰构成」（27课，行16998）。
- 「一般来说，第二、三类的买点，都有一个三段的走势，第三段往往都破点第一段的极限位置，从而形成盘整背驰」（行17000）。
- 位置决定意义：「小级别的盘整背驰，意义都不太大，而且必须结合其位置。如果是高位，那风险就更大了，往往是刀口舔血的活动；但如果是低位，那意义就不同了」（行16998）。

### 2.4 历史性底部＝大级别盘整背驰（类第一/第二类买点）

- 「盘整背驰最有用的，就是用在大级别上，特别是至少周线级别以上的，这种盘整背驰所发现的，往往就是历史性的大底部」（27课，行17002、16979）。
- 类第一类买点：「站在最大的级别看，所有股票都只有一个中枢……绝大多数的股票都其实是一个盘整，这时候就要用到这因为盘整背驰而形成的类第一类买点了。这个级别，至少应该是周线以上」（行17156）。
- 类第二类买点：「在大级别里，如果不出现新低，但可以构成类似第二类买点的买点，在 MACD 上，显示出类似背驰时的表现，黄白线回拉 0 轴上下，而后一柱子面积小于前一柱子的」——600685 季线 2.21 元例，「2.21 元的相应区间的寻找，也是按上面级别逐步往下找背驰段的方法实现」（行17158，image260）。
- 可靠性分级：周线找出的「不一定是历史性大底，可能就是一个比较长线的底部。如果把这种方法用在日线上，也是可以的，但相应的可靠性就不是那么绝对了」（行17160）。

### 2.5 「围绕中枢的盘整背驰」判据与防转化

- 围绕中枢震荡的两段比较即可：600331 例「5 分钟中枢在昨天就形成了……010935 前面是一段，011410 后面是一段，这两段就可以比较了」（27课回复，行17246）。
- **防转化为第三类买卖点**（核心风险）：「盘整背驰一定要防止变成第三类买卖点，这要配合大级别综合看。例如一个 30 分钟上的下跌刚开始破位，那 5 分钟上的盘整背驰就转化为第三类卖点的几率就 99%了。所以这种盘整背驰，一般都没必要参与。如果 30 分钟是刚开始上涨的，5 分钟向下的盘整背驰反而是一个好的买点了」（27课回复，行18158-18161）。
- 「背驰就是背驰，没有什么假背驰，错了是因为你判断错了，最多错误都是发生在把盘整背驰转化为第三类买卖点给搞成背驰了。能把这关过了，你的水平可以上初中了」（27课回复，行17187）。学历标准：「精通分辨盘整背驰与背驰，躲过盘整背驰转化为第三类买卖点的是小学毕业」（行17171）。

## 三、背驰段精确界定（37课/43课）

### 3.1 背驰段定义（27课）

「先补充一个定义：就是在某级别的某类型走势，如果构成背驰或盘整背驰，就把这段走势类型称为某级别的背驰段」（27课，行17002）。

### 3.2 背驰段（c 段）的五个成立条件（37课正文 + 读者「石猴」归纳，行24510-24555）

1. **A、B 是同级别的中枢**——否则只能按围绕大中枢的震荡处理，最多盘整背驰（行24432）；
2. **c 必然是次级别的**，「也就是说，c 至少包含对 B 的一个第三类买卖点，否则，就可以看成是 B 中枢的小级别波动，完全可以用盘整背驰来处理」（行24434）——**背驰段的精确起点由此被界定：c 自对最后一个中枢 B 的第三类买卖点（含触发它的次级别离开段）展开**。原文未用「第三类卖点后」字样逐字表述起点【待核：起点字面】，但「c 至少包含对 B 的一个第三类买卖点」与 61课「65 开始的一段」（65 为对 60-65 中枢的离开点）口径一致；
3. **b 在级别上不能大于 c**；b 可以小于次级别，「力度最大的就是连续的缺口」；反之「如果 b 是次级别，而 c 出现连续缺口……c 是背驰的可能性就很小了，就算是，最终也要特别留意，出现最弱走势的可能性极大」（行24434-24437）；
4. **c 必须创新高/新低**：「如果 a+A+b+B+c 是上涨，c 一定要创出新高；a+A+b+B+c 是下跌，c 一定要创出新低。否则，就算 c 包含 B 的第三类买卖点，也可以对围绕 B 的次级别震荡用盘整背驰的方式进行判断」（行24437）；
5. **c 至少包含两个次级别中枢**：「由于 c 包含 B 的第三类买卖点，则 c 至少包含两个次级别中枢，否则满足不了次级别离开后次级别回拉不重回中枢的条件。这两个中枢构成次级别趋势的关系，是最标准最常见的情况，这种情况下，就可以继续套用 a+A+b+B+c 的形式进行次级别分析确定 c 中内部结构里次级别趋势的背驰问题，**形成类似区间套的状态**，这样对其后的背驰就可以更精确地进行定位了」（行24437）。

> 读者总结后缠师出思考题：「形成（加定语趋势背驰段）三买的两个次级别走势类型，有哪几种方式组合方式」，整理者注「同分 3 买。趋势和盘任意组合」（行24515-24517）。

### 3.3 背驰段 ≠ 背驰（进入背驰段后可被否定，43课）

- 「原来备驰段也不一定发生备驰啊」之问，缠师答：「这很正常，如果用 MACD 来辅助看，拉回 0 轴后再上去，都可以先看成是进入背驰段……但最后是否黄白线创新高，在刚走的时候是不可能知道的，然后就要看小级别的结构，如果小级别的走势特别强，使得黄白线创出新高，那就不存在背驰的问题了」（43课回复，行26691）。
- 同义表述（43课正文）：「这个背驰段并不一定就演化成背驰，因为，小级别的延伸足以使得大级别最终摆脱背驰，这与当下的走势判断相关」（行26529）。
- 61课操作化：「在和 55-60 比较时，都可以先假设是进入背驰段。而当走势实际走出来，一旦力度大于前者，那么就可以断定背驰段不成立，也就不会出现背驰」（行33016-33017）。
- 背驰段的结束判定：15 分钟黄白线拉回 0 轴只是「一个条件，还有必要看其后股价新低后是否创新低，更精确的判断，可以参考 5 分钟的图。也就是这个背驰段什么时候结束」（27课回复，行17257）。

### 3.4 同级别比较的要求与 MACD 图的级别选择（43课定位的「补习」要点，散见各课）

- 背驰有级别：「背弛同样有级别的问题，一个 1 分钟级别的背弛，在绝大多数的情况下，不会制造一个周线级别的大顶，除非日线上同时也出现背弛」（24课，行14395）。
- 背驰级别 ≤ 当下走势级别：「背驰的级别不可能大于当下走势的级别，例如一个 30 分钟级别的背驰，只可能存在于一个至少是 30 分钟级别的走势类型中」（43课，行26527-26528）。
- 说背驰必先说级别：「背驰和均线没关系。说背驰，你首先要说级别，否则无从说起」（27课回复，行17706）。
- MACD 图的级别选择＝跟着「黄白线是否有 0 轴回拉」走：「对于 000572，现在看日线的 MACD 意义不大，该看的是 30 分钟以下级别的，因为背弛首先需要的是回拉 0 轴的黄白线，000572 日线上现在怎么会有 0 轴的回拉？」（25课回复，行15280）。又如宝钢例：「宝钢 15 分钟根本没有背驰……黄白线都没拉回去，怎么可能有背驰？该背驰是典型的 1 分钟背驰」（27课回复，行17230）；601628 例「黄白线没拉回 0 轴前是不会有背驰的。最多是正在形成 1 分钟的背驰」（行17795）。600668 涨停干扰例：15 分钟「不算，1 分钟算」（行17515）。600177 例：「错，只是一个比 1 分钟还低的背驰」（行17532）。
- 多波下跌中找「最后一波」的程序：「你首先要形成趋势，也就是要有两个中枢。最后一个出现后，就意味着进入背驰段，也就是说进入 5 分钟的底部区域。然后就找 1 分钟的看精确买点」（27课回复，行18097-18099）；「关键是先找到大一点级别的背驰段，然后再用小级别的背驰来找精确买点……最好就是在 30 分钟的背驰段用 5 分钟找买点，短线这样就比较安全了」（行18062-18063）。
- 低于 1 分钟的「次级别背驰」替代观测法：「1 分钟是被看到的最低一个图，如果要发现比 1 分钟还低的精确走势，可以单纯参考 1 分钟 MACD 的柱子对比，这时候黄白线一般都是远离 0 轴，然后形成绿柱子放红后再次放绿，但绿柱子比前一波要小，但股价创低，这其实构成了 1 分钟的次级别的背弛，如果有 1 秒图，这就能发现了」（27课，行17415-17416，image273）。最低精度极限：「最精确的、最低级别的图，就是每一笔成交按次序排列而成的图，现在看的 1 分钟图，已经有点粗糙了」（24课回复，行14644）。

### 3.5 背驰点作为走势分解的分界（43课）

- 标准情况：「出现一个 30 分钟的背驰，从而完成一个 30 分钟级别走势类型……前后两个走势类型，就以该背驰点为分界」（行26542）。
- 小转大情况：c 中 1 分钟背驰后演化出 30 分钟中枢 C——「如果 C 和 B 没有任何重叠，那就意味着原来的 a+A+b+B+c 并不是一个完成了的 30 分钟走势类型，该走势类型将延伸为 a+A+b+B+c+C」；「如果 C 和 B 有重合，那么 a+A+b+B+c+C=a+A+b+（B+c+C），其中（B+c+C）必然演化成一个日线中枢……如果一定要按 30 分钟级别来进行同级别分解，那么该分解点就是那 1 分钟的背驰点，a+A+b+B+c+C=（a+A+b+B+c）+C」（行26548-26551）。
- 回复澄清（重合即扩展是「进行式」）：「2 个 30 分钟中枢 B\C 如果有区间重合部分，必然扩展成一个日线级别的中枢，并不是说（B+c+C）就是形成了一个日线中枢。（注：禅师的意思为进行式非完成式--需 3 买确认）」（行26870-26871，括注为整理者批注）。

## 四、小转大（44课，关联29课）

### 4.1 两种转折方式（43课铺垫）

- 「转折必然由背驰导致，但背驰导致的转折并不一定是同一级别的」（43课，行26508）。
- **一、背驰级别 = 当下走势级别**：「一个 30 分钟的走势类型，出现一个 30 分钟级别的背驰，那么这个背驰至少把走势拉向该 30 分钟走势最后一个中枢」——回跌**必然**（行26528-26529、26537）。
- **二、背驰级别 < 当下走势级别**（小转大）：30 分钟 a+A+b+B+c 中「在 c 中出现 1 分钟背驰，而 c 对 b 在 30 分钟级别并没有出现背驰，这时候并不必然保证 c 的 1 分钟转折的最终走势就一定不跌回 B 里，但即使这个回跌出现，其形式也和第一种情况不同。这第二种情况，必然要先形成一个比 1 分钟级别要大的中枢，然后向下突破，最终形成回跌到 B 中的走势」（行26530-26533）。两者区别：「在第一种情况中，其回跌是必然的，而第二种情况，在形成一个比 1 分钟大的中枢后，并不必然回跌，可以往上突破，使得 a+A+b+B+c 继续延伸」（行26537）。
- 高发位置：「这种小级别背驰最终转化成大级别转折的情况，最值得注意的，是出现在趋势走势的冲顶或赶底之中，这种情况一般都会引发大级别的转折」，例 20070104 工行、20061207 北辰、20070122 水井坊（行26540）。与 24课回复呼应：「一个快速赶顶的股票，最后段的上升往往就是一分钟上的趋势的延伸，这时候，一旦出现背驰，就会急促下跌到延伸的启动位置……特别在快速的市场变动节奏中，往往一个很低级别的背驰就造成很快速的下跌」（行14524）。
- 1 分钟只是举例：「即使是 1 分钟以下背驰，道理也是一样的，那 1 分钟背驰只是一种举例」（44课回复，行27186）。

### 4.2 小转大的机制与判别定理（44课）

机制：30 分钟 a+A+b+B+c，c 是 1 分钟背驰最终拉回 B，则 c 内部——

- 「c 至少要包含一个 5 分钟的中枢，否则，中枢 B 就不可能完成，因为这样不可能形成一个第三类的买点」（行26925）；
- 「不妨假设 c\` 是 c 中最后一个 5 分钟的中枢，显然，这个 1 分钟的顶背驰，只能出现在 c\` 之后，而这个顶背驰必然使得走势拉回 c\` 里，也就是说，整个运动，都可以看成了围绕 c\` 的一个震荡，而这个震荡要出现大的向下变动，显然要出现 c\` 的第三类卖点，因此，对于那些小级别背驰后能在最后一个次级别中枢正常震荡的，都不可能转化成大级别的转折」（行26926）。

**缠中说禅小背驰-大转折定理**：「小级别顶背驰引发大级别向下的必要条件是该级别走势的最后一个次级别中枢出现第三类卖点；小级别底背驰引发大级别向上的必要条件提是该级别走势的最后一个次级别中枢出现第三类买点」（行26927-26929）。

- **只有必要条件，没有充分条件**：「不能有一个充分的判断使得一旦出现某种情况，就必然导致大级别的转折。小级别顶背驰后，最后一个次级别中枢出现第三类卖点并不一定就必然导致大级别的转折」（行26933）。
- 对照：「背驰级别等于当下的走势级别」必然回拉最后中枢，「如果你刚好是该级别为操作级别的，只要在顶背驰时直接全部卖出就可以」（行26934）。

### 4.3 什么时候小背驰只产生小反弹、什么时候引发大转折（操作判别程式）

按 30 分钟级别操作者面对 c 中小级别顶背驰（行26941-26947）：

1. 小级别顶背驰「必然首先至少要导致一个 5 分钟级别的向下走势」；
2. 若该向下走势**没有回到**「构成最后一个 30 分钟中枢的第三类买点那个 5 分钟向下走势类型的高点」→ 不必理睬（走势在可接受范围内）；最强走势甚至「不会接触到包含最后一个 30 分钟中枢第三类买点那 5 分钟向上走势类型的最后一个 5 分钟中枢」→ 更无须理睬；
3. 若**跌破**该高点 → 「任何的向上回抽都必须先离开」。
4. 筹码较多者的两步法：当「包含最后一个 30 分钟中枢第三类买点那 5 分钟向上走势类型的最后一个 5 分钟中枢（即 c\`）出现第三类卖点，就必须先出一部分，然后在出现上一段所说的情况时在出清。当然，如果没有出现上一段所说的情况，就可以回补，权当弄了一个短差」（行26953-26954）。
5. 为什么不在 1 分钟背驰时就走：「这是与你假定操作的级别相关的，而走势不能采取预测的办法……你不可能按 30 分钟操作，而一见到 1 分钟顶背驰就全部扔掉，这就变成按 1 分钟级别操作了」（行26958-26960）；大资金可「把部分筹码出掉，然后根据后面的回调走势情况决定回补还是继续出」（行26964）。底背驰反之（行26964）。
6. 不破前高的处理（43课回复，39课同级别分解程序的衔接）：「有一种特殊情况是不出现盘整背驰的，就是小级别变大级别的情况，这种情况，如果不破前期高点，那只是一个新中枢，所以当然持有，如果破了，那就一定要走，除非出现强力不背驰创新高的情况」（行26750）；且「是（待反弹时走），不能杀跌……如果精细点，可以不等跌破就先走掉」（行26775-26780）。

### 4.4 与 29课「转折的力度与级别」的关系

43课开头整理者注：「小转大的情况在 29 课已经表达清楚，此处再细化」（行26505）。29课提供转折结果的完全分类与强弱判别：

- 背驰-转折定理的三种结果（行20077-20081）：①最后中枢级别扩展；②更大级别盘整；③该级别以上反趋势。
- 最弱情况＝中枢级别扩展：背驰后反弹「一定触及最后一个中枢的 DD=min(dn)」，只触及 DD 的反弹「就是背弛后最弱的反弹，这种反弹，将把最后一个中枢变成一个级别上的扩展」（行20082-20083）。
- 与盘整背驰转化三卖的区分：「那种情况下，反弹的级别一定比最后一个中枢低，而这种情况，反弹的级别一定等于或大于最后一个中枢的」（行20087）。
- 「下跌+盘整」中盘整中枢级别必大于下跌中的中枢级别（9 段次级别数量平衡论证，行20090-20104）；而「上涨的中枢，不一定大于下跌中的中枢」（行20091）。
- 强弱判别程序：「关键就是看反弹中第 1 个前趋势最后一个中枢级别的次级别走势……是否重新回抽最后一个中枢里，如果不能，那第一种情况的可能就很大了，而且也证明反弹的力度值得怀疑」（行20108-20109）。
- 29课实例即区间套：「这次 20070206 的反弹，用 5 分钟背驰段，然后考察 1 分钟以及 1 分钟以下级别的背驰进行精确定位，可以极为精确地把握这个底部」（行20110）。
- 关联逻辑：29课回答「某级别背驰之后会发生什么、力度多大」（转折的下界与分类），44课回答「比当下级别小的背驰何时升格为大级别转折」（必要条件＝最后一个次级别中枢的三类卖/买点）。两者合用即对「背驰→转折」全谱系的当下判别。

## 五、区间套定位程式（61课为主，27课奠基）

### 5.1 理论定理（27课）

- 思想来源：「学过数学分析的，都应该对区间套定理有印象。这种从大级别往下精确找大级别买点的方法，和区间套是一个道理」（行17055）。
- **缠中说禅精确大转折点寻找程序定理**：「某大级别的转折点，可以通过不同级别背驰段的逐级收缩范围而确定」（行17064-17066）。
- 程序表述：「某大级别的转折点，先找到其背驰段，然后在次级别图里，找出相应背驰段在次级别里的背驰段，将该过程反复进行下去，直到最低级别，相应的转折点就在该级别背驰段确定的范围内」（行17068）。
- 嵌套性（万科例）：「季度图上的第三段，在月线上，可以找到针对月线最后中枢的背驰段，而这背驰段，一定在季度线的背驰段里，而且区间比之小，把这个过程从月线延伸到周线、日线、30 分钟、5 分钟、1 分钟，甚至是每笔成交，这区间不断缩小」，理论上「就这一笔是万科历史底部的最后一笔成交」（行17057-17060）。
- 精度边界：「这些级别不是无限下去的，因此，理论上并不能去证明就是一个如极限一样的点状情况的出现，但用这种方法去确认一个十分精确的历史底部区间，是不难的」（行17062）；「1 分钟的背驰段，一般就是以分钟计算的事情，对于大级别的转折点，已经足够精确了」（行17070）。

### 5.2 61课标准图解的逐步骤程式（2007-06-20 上证 1 分钟，节点 54-74，image546）

**Step 0 选定比较对象**：「只要是围绕一中枢的两段走势都可以比较力度。显然，对于 60-65 这个 1 分钟中枢，55-60 与 65 开始的一段之间就可以比较」（行33015）。

**Step 1 先假设进入背驰段，等走势证伪**：「65 开始的走势，由于没实际走出来，所以在和 55-60 比较时，都可以先假设是进入背驰段。而当走势实际走出来，一旦力度大于前者，那么就可以断定背驰段不成立，也就不会出现背驰」（行33015-33017）。

**Step 2 递归进入内部结构**：「在没有证据否定背驰之前，就要观察从 65 开始的一段其内部结构中的背驰情况，这种方法可以逐次下去，这就是区间套的定位方法，这种方法，可以在当下精确地定位走势的转折点」（行33017）。

**Step 3 新高约束**：「对于 65 开始背驰段的内部走势，当下走到 69 时，并不构成任何背驰，为什么？因为背驰如果没有创新高，是不存在的。所以，只有等 70 点出现时，大盘才进入真正的背驰危险区」（行33018-33019）。

**Step 6 四重背驰段嵌套，定出背驰点**：「65 开始的走势是第一重背驰段，69 开始的是第二重背驰段，也就是 65 开始背驰段的背驰段，而 71 开始的是第三重背驰段……最后当下考察 71 开始的走势，从走势上红尖头以及 MACD 上红尖头可以当下知道，71 的内部背驰也出现，也就是第四重的背驰段出现了」（行33028-33029）；「72 点这个背驰点的精确定位，是由 65 开始背驰段的背驰段的背驰段的背驰段构成的，这就构成一个区间套的精确定位，这一切，都可以当下地进行」（行33030-33033）。

### 5.3 区间套与「非同级别分解」/低级别操作的关系

- 操作级别的相对性（61课开篇）：「如果你的操作级别是 1 分钟级别的，那么 1 分钟的顶背驰你就该走了，至于后面的跌幅是大是小，和你有什么关系？……反之，如果你的操作级别是月线的，那么 1 分钟的顶背驰和你有什么关系？」（行32979-33030）。区间套使任何大级别买卖点都能在最低可见级别上**当下**兑现，这正是把操作精度下沉到 30m 以下级别（1m/5m 乃至分笔）的理论依据：大级别背驰段框定区间，低级别背驰段逐级收缩到可执行的那一段。
- 24课回复对「只看日线行不行」的回答从反面支撑：「当然可以，但前提是你永远不打短差……因为很多判断必须用到次级别的走势，甚至次次级别的走势」（行14661）。
- 与同级别分解的分工：43课给出小转大时 30 分钟同级别分解点＝那个 1 分钟背驰点（行26551）——即**跨级别的背驰点可以充当本级别分解的分界**；区间套则反向地用次级别、次次级别走势去精确化本级别的转折点。两者合起来构成「非同级别分解」式操作（用低于操作级别的结构处理操作级别的买卖点）。
- 【待核】「非同级别分解」这一术语在本主题各课正文中未出现（属后续课程术语）；61课页内有 2020-05-24 整理者批注：「其实这个区间套操作是按照中枢来的，与走势类型的区间套运用有所区别」（行32974），提示区间套存在「按中枢比较」（61课图解，围绕中枢两段比力度）与「按走势类型逐级找背驰段」（27课定理）两种运用口径。
- 61课图解的级别申明（整理者注，行33325）：2007-06-20 至 7-06 的走势「为 1 分趋势后接更大级别盘 5 分中枢再接 1 分趋势区间套，即下跌+盘+下跌」。37课图注同类：「禅师 58 课分段前后的级别不同，下图 30 分中枢为递归后的 5 分中枢」（行24466-24468）——读图时须注意分段定义前后的级别口径差异。

## 六、回复中的重要澄清（精选12条）

1. **趋势内中枢的方向结构**：「如果是向上的走势，里面的中枢一定是下-上-下的，向下的相反」——「你首先要搞清楚中枢形成的三段的方向是怎么开始的，不是随便三段就是的」（24课回复，行14495、14542）；理由：「在上升中形成中枢的地方必然对应着调整，当然是从高点开始算起」（25课回复，行15361）。
2. **标准趋势至少9段**：两个中枢 6 段＋底部回拉、连接、最后冲刺各 1 段（24课回复，行14566-14568）；43课回复补充「a\c 也可以不存在……标准就是都存在的那种」（行26861）。
3. **没创新高没有背驰**：「三角形，没有新高，怎么会有背驰？先把概念搞清楚」（24课回复，行14675）；「创出新高也不一定是趋势……所以还有盘整背弛判断」（行14626）；44课回复把边界划清：「创新高或新低才有背驰或盘整背驰的可能。未创新高的情况，其实可以按中枢震荡的方式去看……但和背驰不是同一样东西」（行27230）。
4. **黄白线必须先回拉0轴**：「背驰需要多少个条件？光柱子缩短就背驰？前面的黄白线有回拉 0 轴吗？」（25课回复，行15346）；「如果 B 段不是回抽 0 轴附近，就根本不满足条件，否则任意三段都可以用 MACD 判断背驰了，那不乱套了？」（27课回复，行18288）；「黄白线没拉回 0 轴前是不会有背驰的」（行17795）。MACD 级别选择随之确定：哪个级别有 0 轴回拉就看哪个级别的 MACD（25课回复，行15280）。
5. **背驰回跌力度与级别的多级别综合**：「如果日线上在上涨的中段刚开始的时候……5 分钟即使出现背驰，其下跌力度显然有限，所以只能打点短差，甚至可以不管。而在日线走势的最后阶段，特别是上涨的延伸阶段，一个 1 分钟的背驰足以引发暴跌……绝对不能一看背驰就抛等跌 50%」（24课回复，行14685；000682 个例行14580-14582）。
6. **没有假背驰**：「背驰就是背驰，没有什么假背驰，错了是因为你判断错了，最多错误都是发生在把盘整背驰转化为第三类买卖点给搞成背驰了」（27课回复，行17187、17454）。
7. **盘整背驰的好坏取决于大级别方向**：30 分钟下跌刚破位→5 分钟盘整背驰转化三卖几率 99%，不参与；30 分钟刚开始上涨→5 分钟向下盘整背驰反而是好买点（27课回复，行18158-18161）。
8. **庄家不在走势之外**：「如果他可以拉抬，自然就不会出现背驰；如果他边拉边出，走势上自然留下痕迹，就是背驰。注意，走势一切力量的综合结果，没必要单独考虑某种力量」（24课回复，行14538-14540）。
9. **双次拉回**：「MACD 在 10 点 17 分更靠近 0 轴，这叫双次拉回，一般双次拉回都上不去，一定有再次下跌的。一般这种双次来回的第二次，都是构成下跌中的第一个中枢，特别在跌破前面中枢后，这其实刚好构成一个标准的最小级别的第三类卖点」（25课回复，行15098-15100）。
10. **背驰段可被否定**：「拉回 0 轴后再上去，都可以先看成是进入背驰段……如果小级别的走势特别强，使得黄白线创出新高，那就不存在背驰的问题了」（43课回复，行26691）。
11. **小转大分析以背驰级别为前提**：对网友推导 C1-C5 诸结论，缠师指出「你这些结论都有一个前提，就是背驰的级别是 30 分钟的，否则，一个小级别背驰，完全可以不这样走」（44课回复，行27282）；且「1 分钟背驰只是一种举例」，1 分钟以下道理相同（行27186）。
12. **MACD 0轴盘整对应的中枢级别只是下界**：「MACD 在 0 轴附近盘整以及回抽 0 轴所形成的中枢，不一定就是相应级别的中枢，而是至少是该级别的中枢」（25课，行14965，正文性质但属答疑式补充）。另有操作哲学三连：「所有情况都逃不过高位背驰卖，低位背驰买，不预测」（25课，行15048）；「有卖点就卖，有买点就买……即使你是中线持有，5 分钟、30 分钟背驰，也可以先卖部分出去，下来再回补」（25课，行15063）；1 分钟背驰打短差「这部分资金绝对不能追高」且机动资金占 1/4-1/3（25课回复，行15091）。

## 八、可验证判据清单

> 编号 C5.x；「行」均指 chanlun.txt 行号（=pNNNN）。

**A. 趋势背驰成立条件**

- C5.1 背驰必须发生在趋势中：a+A+b+B+c 中 A、B 为同级别中枢；若 A 级别>B，整体只是围绕 A 的震荡，至多盘整背驰。（行24432）
- C5.2 背驰不会发生在趋势第一个中枢之后；至少第二个中枢之后。日线以上级别第二中枢后即背驰的占比 ~90%；下跌超过 4 个中枢极罕见。（行16993、16996、17443-17445）
- C5.3 比较段＝围绕最后一个中枢 B 的前后两段同向走势：b（=24课A段）与 c（=24课C段）比，**不是 c 与 a 比**。（行14400-14401、33015、24554-24556）
- C5.4 c 必须是次级别走势，且至少包含对 B 的一个第三类买卖点（否则按 B 的小级别波动用盘整背驰处理）。（行24434）
- C5.5 b 的级别不能大于 c；b 可小于次级别（极限为连续缺口）；若 b 为次级别而 c 现连续缺口，c 背驰概率很小，即便背驰也多为最弱走势前兆。（行24434-24437）
- C5.6 上涨趋势的 c 必须创新高、下跌的 c 必须创新低；否则只能按围绕 B 的次级别震荡做盘整背驰判断。（行24437）
- C5.7 c 内部至少包含两个次级别中枢（构成次级别趋势），可对 c 继续套用 a+A+b+B+c 做次级别背驰分析——区间套入口。（行24437、17445-17447）
- C5.8 趋势的最小段数：标准两中枢趋势至少 9 段次级别走势（6 段中枢内＋首段＋连接段＋冲刺段）。（行14566-14568）
- C5.9 向上走势中的中枢必以「下-上-下」开始（向下相反）——中枢三段方向校验。（行14495、15361）

**B. MACD 辅助程式**

- C5.10 必要条件：最后一个中枢 B 须把黄白线（DIFF/DEA）回拉至 0 轴附近；黄白线未回拉 0 轴前不存在该级别背驰。（行14401、17795、18288）
- C5.11 标准判定：C 段完成时 MACD 柱子面积（向上看红柱、向下看绿柱）< A 段（=b 段）对应面积。（行14401）
- C5.12 三判据（任一不创新高即背驰信号）：①黄白线不创新高/新低；②柱子面积；③柱子伸长高度。「只要其中一个符合就可以是一个背弛的信号，两个都满足就更标准。」（行14940、17048）
- C5.13 面积乘 2 估计：柱子伸长力度变慢时，已出现面积×2 可当作该段最终面积——背驰可在末段当下判定，无须等回跌。（行14407）
- C5.14 C 段多波时各柱面积累加后与 A 段比较；C 段未形成中枢前「走势必完美」判 C 未完，不得提前判背驰；未创新高的波不参与背驰判定。（行14449-14462）
- C5.15 MACD 失效场景替代：1 分钟急拉用柱子乖离极限（两三次冲极限不过即回调）；连续一字涨停改用 1 分钟中枢上移＋大周期（30m）MACD 红柱低点渐低触 0 轴警告。（行14837-14840、14884-14885）
- C5.16 双次拉回：黄白线两次靠近 0 轴的回拉，一般上不去、必有再跌；第二次回拉常构成下跌的第一个中枢，破位后即最小级别三卖。（行15098-15100）
- C5.17 MACD 0 轴盘整/回抽对应的中枢级别只是下界（「至少是该级别的中枢」）。（行14965）

**C. 盘整背驰**

- C5.18 盘整背驰三情况（向上为例）：①C 不破中枢且面积小→必回跌；②C 破中枢且面积小→先出，回跌不回中枢→次级别一买回补＝本级别三买；③回跌回中枢→盘整继续。（行14420）
- C5.19 趋势背驰后回跌必至少回到最后中枢 B 内（可预知最小跌幅）；盘整背驰无此保证。（行14463、14683、26529）
- C5.20 第一/三段两个走势类型即可比较力度，不要求是趋势；盘整对盘整亦可比。（行17000、24555）
- C5.21 多数第二、三类买点由盘整背驰构成；第一类买点多由趋势背驰构成。（行16998）
- C5.22 周线以上级别的盘整背驰（类一买/类二买）用于历史性大底；类二买判据＝不创新低＋黄白线回拉0轴后柱子面积小于前一柱。（行17002、17156、17158）
- C5.23 盘整背驰转化第三类卖点的先验：大级别（如30m）下跌刚破位时，小级别（5m）盘整背驰转化三卖概率 ~99%，不参与；大级别刚启动上涨时，小级别向下盘整背驰是好买点。（行18158-18161）
- C5.24 未创新高/新低则背驰与盘整背驰皆不存在，按中枢震荡力度比较处理。（行27230、14675）

**D. 背驰段**

- C5.25 背驰段定义：构成背驰或盘整背驰的那段走势类型＝该级别背驰段。（行17002）
- C5.26 进入背驰段的操作化判定：MACD 拉回 0 轴后再离开 0 轴的段都先假设为背驰段；实际力度（新高/面积）超过前段即否定背驰段。（行26691、33016-33017、26529）
- C5.27 背驰段结束的精确判定下沉一个级别看（如 15m 背驰段结束看 5m 图）。（行17257、18062-18063）
- C5.28 低于最低可见级别（1分钟）的次级别背驰替代判据：黄白线远离 0 轴＋柱子缩放序列（绿柱放红再放绿、绿柱缩小而价创新低）。（行17415-17416）

**E. 背驰后果与小转大**

- C5.29 背驰-买卖点定理：任一背驰必造某级别买卖点；任一买卖点必源自某级别背驰。（行14396）
- C5.30 背驰-转折定理：某级别趋势背驰→最后中枢级别扩展 ∣ 更大级别盘整 ∣ 该级别以上反趋势（三选一完全分类）。（行20077-20080、26508）
- C5.31 最弱结果判别：背驰后第一波次级别反弹只触及最后中枢 DD=min(dn) 而回不到中枢内→中枢级别扩展概率大、反弹力度可疑。（行20082-20083、20108-20109）
- C5.32 「下跌+盘整」中盘整的中枢级别必大于下跌内部中枢级别；「下跌+上涨」的上涨中枢级别无此要求。（行20090-20104）
- C5.33 背驰级别 ≤ 当下走势级别；背驰级别=走势级别时回拉最后中枢是必然；背驰级别<走势级别（小转大）时回拉非必然，必先形成一个大于背驰级别的中枢再择向。（行26527-26537）
- C5.34 小背驰-大转折定理（必要非充分）：小级别顶背驰引发大级别向下 ⇒ 该级别走势最后一个次级别中枢（c\`）出现第三类卖点；底背驰反之。c\` 不破、震荡正常者不可能转化大转折。（行26925-26933）
- C5.35 小转大操作线（30m 操作者）：小背驰后的 5m 向下走势未回到「构成最后一个 30m 中枢三买的那段 5m 回调的高点」→不理；跌破该高点→任何向上回抽必须先离开（不杀跌，等反抽/盘整背驰出）；筹码多者在 c\` 三卖先减仓。（行26941-26954、26775-26780）
- C5.36 小转大高发位：趋势的冲顶/赶底（小级别趋势延伸末端），此时低级别背驰常引发对称急跌至延伸启动位。（行26540、14524、14685）
- C5.37 小转大后的同级别分解：背驰后新生中枢 C 与 B 无重叠→原走势类型延伸（a+A+b+B+c+C）；有重叠→(B+c+C) 走向更大级别中枢（进行式，需三买确认），30m 同级别分解点取那个小级别背驰点。（行26548-26551、26870-26871）

**F. 区间套**

- C5.38 精确大转折点寻找程序定理：某大级别转折点可由不同级别背驰段的逐级收缩范围确定；程序＝找本级别背驰段→在次级别图中找该背驰段内的背驰段→反复至最低级别。（行17064-17068）
- C5.39 嵌套保证：次级别背驰段必含于本级别背驰段内且区间更小（季→月→周→日→30m→5m→1m→分笔）。（行17057-17060）
- C5.40 精度边界：级别非无限可分，无数学极限点；1 分钟背驰段（以分钟计）对大级别转折点已足够精确。（行17062、17070）
- C5.41 当下递归规则：未被否定前先假设进入背驰段；走出来力度大于前段→背驰段不成立；未否定→转入内部结构找次一重背驰段，逐次进行（61课四重嵌套：65→69→71→71内部，定位 72）。（行33015-33033）
- C5.42 每一重内部仍受「创新高才有背驰」「相邻同向段先比」约束（69 未创新高不构成背驰；69-70 对 67-68 无盘整背驰则 70 不卖）。（行33018-33020）
- C5.43 三买后的二选一检验：三买后只有「中枢级别扩展」或「新中枢上移」两种前途；走新中枢上移要求三买后的向上段不出现盘整背驰，否则向扩展/转折倾斜。（行33020-33022）
- C5.44 区间套买卖执行按操作级别定仓位：背驰点出现「卖是唯一的选择，区别只在于卖多少」；操作级别≤5m 全清，大级别按可容纳震荡对冲。（行33035-33037、32979-32983）
- C5.45 二、三类卖点重合（61课74点：二卖兼 69-72 中枢三卖）→其后力度值得关注；三类买卖点结合律校验：至少 5 段次级别（3段中枢+1段离开+1段回试）。（行33043-33050）
- C5.46 实战安全级差：用大一级背驰段框区间、小一级背驰找点（30m 背驰段内用 5m 找买点比 5m 段内用 1m 更安全）。（行18062-18063）

### 三条最重要发现（摘要）

1. **背驰比较段是 c 与 b（围绕最后一个中枢的前后两段），且 c 有五个硬条件**——尤其「c 必须次级别且含对 B 的三买卖点」「c 必创新高/新低」「c 至少含两个次级别中枢」。这五条（37课，行24432-24437）使「背驰段」成为可递归对象，直接派生区间套；工程实现时不能只比 MACD 面积。
2. **MACD 程式是「0 轴回拉」为必要门槛 + 三判据任一不创新高即信号**（行14401、14940、17048、18288）：先验黄白线被最后中枢拉回 0 轴，再比黄白线高度/柱面积/柱高度；未创新高的段根本不进入背驰判定（按中枢震荡处理，行27230）。
3. **小转大只有必要条件没有充分条件**：判据＝最后一个次级别中枢 c\` 的第三类卖/买点（44课定理，行26927-26933），操作线＝是否跌破「构成最后中枢三买的那段次级别回调高点」；而 61课区间套则给出全部背驰的当下定位通用程序（先假设背驰段→递归内部→逐重收缩，四重嵌套例，行33015-33033），两者合起来是低于 30m 级别精确操作的完整理论依据。
