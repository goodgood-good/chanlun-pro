## 0. 范围与非范围

- **范围**：单标的、单一基础周期序列上，如何把走势划分成中枢/走势类型，并据此给出买卖点与精确定位。
- **非范围**：选股、仓位、多标的、回测框架、图表显示。
- **一句话总纲**：已完成走势 → 中枢唯一确定；未完成走势 → 多假设并存、随走势坍缩。

## 1. 总架构与心智模型

### 1.1 心智模型：增量文法解析器
缠论的递归定义（走势类型→至少三段次级别走势类型；中枢→前三段重叠……）本质是一套**上下文无关文法**。

- **已完成走势** = 已确定的 parse（唯一规范树）。
- **未完成的右尾** = 带歧义的后缀 → 多棵合法 parse 树并存。
- **新 K 线 / 次级别走势完成** = 新 token 进来 → 对所有 parse 树做**剪枝**。

### 1.2 四条架构决策（已定）

1. **多假设并存 + 后验裁决**：未完成段同时维护多个完整合法分解，由后续走势（背驰/买卖点/更高级别）裁决。
2. **歧义节点驱动 + 左侧冻结**：已完成结构冻结为唯一规范解、永不再分叉；分叉**只**发生在右边缘**可枚举**的歧义节点；每个分支必须是一棵**完整合法的递归分解树**（绝非任意滑动窗口）。
3. **右尾分支 provisional 贯通到顶**：低级别右尾分支以「暂定」身份向上递归，高级别即时看到多个可能未来。
4. **纯结构坍缩（无人工上限）**：靠「完成即坍缩 + 延伸≤5 硬上限 + 合法性 + 操作确认」收敛，不设人工 beam 上限。

> 防过拟合是**结构性**保证：左侧冻结（不重审历史）+ 歧义只在可枚举节点产生 + 每分支是完整合法递归树 + 完成即坍缩。

## 2. 级别模型（单基础递归，封顶日线）

**级别 = 递归层级的定义性标签，不是对真实周期图的近似。**

```
1m K线 → 分型 → 笔 → 线段        （级别之下的几何脚手架，不算级别）
   线段          ──构成──▶  L0 中枢   「1分钟级别」
   L0 中枢       ──构成──▶  L0 走势类型「1分钟级别」
   L0 走势类型   ──构成──▶  L1 中枢   「5分钟级别」
   L1 走势类型   ──构成──▶  L2 中枢   「30分钟级别」
   L2 走势类型   ──构成──▶  L3 中枢   「日线级别」     ← 封顶
```

- **走势单位 = 线段**（不是笔）；「1 分钟级别中枢」即线段中枢。
- 「5 分钟级别中枢」**定义为**「由 1 分钟级别走势类型构成的中枢」，以此类推。恰好 4 层，层级即定义，无浮动、无标定。
- 原文背书（第33课）：「用 1 分钟、5 分钟、30 分钟、日线……的级别安排，只是一个简略的方式」——固定周期阶梯是原文亲许的近似形态。
- 笔/线段是**确定性输入**（特征序列标准已使线段划分确定，见 §3.4）；多假设从中枢层开始，笔/线段不进多假设。

## 3. 原文地基（定义与定理）

### 3.1 走势与走势类型（第18课）
- 走势类型：上涨、下跌、盘整。趋势：上涨、下跌。
- **走势分解定理一**：任何级别的任何走势，都可分解成同级别「盘整、下跌、上涨」三种走势类型的连接。
- **走势分解定理二**：任何级别的任何走势类型，都至少由三段以上次级别走势类型构成。

### 3.2 走势中枢（第18课）
- 定义：某级别走势类型中，**被至少三个连续次级别走势类型所重叠的部分**。
- 严格公式（第18课）：前三段 A/B/C 高低点 a1\a2…，**中枢区间 =（max(三个低点), min(三个高点)）= `[max(a2,b2,c2), min(a1,b1,c1)]`**。
- 第20课等价表述（**Z 走势段**口径）：与中枢同向的次级别走势类型称为 Z 段，按时序记其高低为 `gn / dn`。则
  - **核心**：`ZG = min(g1,g2)`（中枢高）、`ZD = max(d1,d2)`（中枢低）→ `[ZD, ZG]`；
  - **包络**：`GG = max(gn)`、`DD = min(dn)` → `[DD, GG]`（含延伸的瞬间波动区间）。
  - 两式等价：相邻段共享端点，故「max(三低)/min(三高)」与「max(d1,d2)/min(g1,g2)」一致。`gn/dn` 是后文 §3.5/§4 双区间与中心定理的统一记号。
- **关键限定**：前三个次级别走势类型必须**都「完成」**才构成中枢。

### 3.3 基本原理与盘整/趋势（第18课）
- 基本原理一：任何级别的任何走势类型**终要完成**。
- 基本原理二：任何**完成**的走势类型，必然包含一个以上的中枢。
- **盘整**：完成的走势类型只含**一个**中枢。
- **趋势**：完成的走势类型含**至少两个依次同向**的中枢，且趋势中**中枢之间绝对不存在重叠**（含瞬间波动/包络的重叠）。

### 3.4 笔与线段（第65–66课，确定性层）
- 线段被笔破坏（第65课）：向上线段分型序列 d1g1…，若存在 i,j（j≥i+2）使 dj≤gi，则向上线段被笔破坏（向下对称）。线段前三笔须有重叠。
- **线段分解定理**：线段被破坏 ⟺ 至少被有重叠部分的连续三笔之一破坏 = 被另一线段破坏。
- **特征序列（第66课，精确化线段终结）**：
  - 向上线段的特征序列由向下笔构成（只考察顶分型），向下线段对称。
  - **缺口**：特征序列相邻两元素无重合区间。对特征序列做非包含处理 → 标准特征序列。
  - **第一种情况**：特征序列顶/底分型第一、二元素间**无缺口** → 线段在该分型处**即时确认**结束。
  - **第二种情况**：第一、二元素间**有缺口** → 线段**暂不确认**，需后一特征序列也出现分型才确认。
- **结论**：线段划分由特征序列精确确定；右边缘最多一根**未完成线段**（pending），其余冻结。

### 3.5 双区间口径（贯穿②③，第18/20课）
- **核心区间 `[ZD, ZG]`**（窄）：管**延伸**（次级波动是否触核心）。
- **本体包络 `[DD, GG]`**：管**扩张/趋势边界**。**口径关键**——本体包络只取**构成中枢的振荡段**，**必须剔除离开段（及远摆延伸）的极值**；否则离开段总朝下一中枢延伸、把包络撑大 → 相邻中枢包络恒重叠 → **趋势恒被误判为扩张**（only-3rd-bspoint 根因 / 第33课 a+A+b+B+c；生产链路 `is_qs(use_core_envelope=True)` 即此口径）。
  - P1 落地口径：本体包络 = **前 3 个定义段的 span**（`envelope(lines[:3])`），剔除延伸/离开段远摆。
- 求值优先级被区间包含关系强制：**延伸（触核心）> 扩张（本体相交）> 趋势/新中枢（本体分离）**。

### 3.6 中枢中心定理（第20课）
- **中心定理一**：中枢延伸 ⟺ 任意 `[dn,gn]` 与 `[ZD,ZG]` 有重叠；若有 Zn 使 `dn>ZG` 或 `gn<ZD` → 必产生高级别中枢或趋势及延续。
- **中心定理二**（趋势 vs 扩张的精确不等式）：前后两同级中枢，
  - 后 `DD>前GG` → 上涨（及延续）；后 `GG<前DD` → 下跌（及延续）；（**包络分离 = 趋势**）
  - 后 `ZG<前ZD` 且 后 `GG≥前DD`（或对称）→ 形成高级别中枢。（**核心分离但包络相交 = 扩张**）
- **走势级别延续定理**：更大级别中枢产生前，本级别走势类型延续；更大级别中枢产生 ⟺ 围绕连续两个同级中枢的波动区间产生重叠。

## 4. 三个歧义节点与坍缩判据

> 未完成走势的歧义是**可穷举**的，只有三类。每类在右边缘分叉、由后续走势坍缩。

### 节点① 末段完成性（最根）
- 输入：确定的线段序列 `[…done, pending?]`。
- 分叉（在「最后一根重叠线段是核心还是离开段」处）：
  - **H1（核心/延伸）**：它是核心成员，中枢还开着 → 预期下一段回来触及核心 `[ZD,ZG]`。
  - **H2（离开/完成）**：它是离开段，中枢此刻已完成。
- **H2 评背驰再分**（§5）：
  - **H2a（走势类型完成）**：离开段背驰 → 吐 provisional 高级别 token，沿贯通到顶上传。
  - **H2b（中枢完成·走势类型延续）**：无背驰 → 中枢 done，走势类型继续。
- **坍缩判据**（中心定理一 / 第三类买卖点）：回试**触及核心 `[ZD,ZG]`** → H1 赢（延伸）；回试**不触核心、另凑三段离开** → H2 赢（= 第三类买卖点，§6）。

### 节点② 延伸/升级
- **延伸判据**：围绕中枢的前后两次级波动**至少一个触及核心 `[ZD,ZG]`**；否则新三段重叠离开原中枢，延伸终止。
- **升级阈值（第33课）**：延伸 ≤ 5 段；第 6 段延伸（共 9 段）→ **决定性升级**成高一级中枢（9 段 = 3 个次级走势类型重合）。
- **态度**：此为第33课「**第一种（级别延伸）多义**」，原文明确要**消除**（≤5 限制）→ 本节点的分支**收敛**，不永久并存。
- 本质 = 节点① 的「延伸 vs 离开」在 6–8 段窗口续命 + 一个「9 段强制升级」硬触发。

### 节点③ 趋势/扩张
- 中枢1 完成后新结构离开核心、凑出候选中枢2：
  - 包络**分离**且依次同向（中心定理二）→ **趋势**。
  - 包络**相交**（中心定理二）→ **扩张 → 升级高级中枢**。
- **右边缘多义**：中枢2 包络随段数生长，H_趋势 / H_扩张 在包络定型前并存；坍缩点 = 中枢2 包络是否越过「触及中枢1 包络」那条线。

## 5. 背驰口径（节点① H2a 用）

### 5.1 比较段
- **盘整背驰（1 中枢）**：`a+A+b`，比 **b : a**（离开段 vs 进入段）。
- **趋势背驰（≥2 中枢）**：`a+A+b+B+c`，比 **c : b**（离开最后中枢 vs 进入最后中枢）。

### 5.2 力度度量（MACD 柱子面积）
- **片 = 比较段（线段）K 线区间内同色柱子的面积和**；上涨段求红柱、下跌段求绿柱。
- **黄白线**：通道式 / 柱子毛糙时以 DEA·DIFF **不创新高**为准。
- **0 轴回拉门槛**：两比较段之间（中枢震荡段）MACD 必须确有回 0 轴，否则两片不可比（中枢震荡 ⟺ MACD 回 0 轴）。

### 5.3 门槛与形态
- **趋势背驰门槛**：离开段 `c` 必须 ≥次级别（至少含对最后中枢的一个第三类买卖点）；否则退回按盘整背驰处理。
- **背驰两形（第33课转折分类）**：
  - **常规背驰**：上述 MACD 面积口径。
  - **非常规背驰 = 小转大**：不走 MACD，用专属信号——本/次级中枢反向突破、次级中枢出现 3 买卖、回抽到达第二中枢 GG·DD。
- **右边缘暂定**：离开段未定型 → 背驰判定为早标签，离开段完成才坐实（早标、不早剪）。

## 6. 三类买卖点 = 节点的坍缩信号

| 买卖点 | 原文判据 | 坍缩的节点 |
|---|---|---|
| **第三类买/卖** | 次级别离开中枢，再以一次级别回试，低点不破 ZG / 高点不破 ZD（第20课） | 节点① H1/H2：不破 ZG → H2 赢（离开坐实）；破 ZG → H1 赢（延伸） |
| **第一类买/卖** | 趋势背驰构成（第18/24课） | 节点① H2a：背驰坐实走势类型完成/反转 |
| **第二类买/卖** | 次级别相应走势的第一类买点构成（买卖点定律一） | H2a 在次级别的递归实例 |

- **买卖点定律一**：任何级别的第二类买卖点，都由次级别相应走势的第一类买点构成。
- **趋势转折定律**：任何上涨转折由某级别第一类卖点构成；任何下跌转折由某级别第一类买点构成。
- **归结**：所有买卖点归根结底都是第一类买卖点，只是级别不同。
- **第三类 nuance**：必须是**第一次**回试；3 买后不必然趋势，可能进更大盘整，但即使盘整也有获利了结高点。
- **核心命题**：**吐一个买卖点 = 坍掉一个节点分支**。「划分」与「出口」是同一件事的两面。

## 7. 区间套（精确定位与跨级裁决）

### 7.1 原文定理（第27课）
**精确大转折点寻找程序定理**：某大级别转折点，先找其背驰段，再在次级别图里找出**相应背驰段在次级别里的背驰段**，逐级进行到最低级别，转折点就在该级背驰段范围内。

- **嵌套性**：次级别背驰段一定**在**大级别背驰段**里**且区间更小；逐级收缩。
- **收敛但不到点**：级别非无限可分 → 收敛到一个小范围（精度 = 最低级别）。
- **操作铁律**：小级别背驰只有**落在大级别背驰段里**才有意义；三重背驰（日⊃5分⊃1分）才精确定位。

### 7.2 双向闭环
- **贯通到顶（自底向上，BUILD）**：从 1m 把各级 provisional 背驰段造出嵌套结构。
- **区间套（自顶向下，READ）**：一个低级买卖点**可操作 + 精确** ⟺ 它是**同向、逐级时间包含**的嵌套背驰链的**最内层**。
- 二者互补：贯通到顶在右边缘造出高级别 provisional，区间套才有东西自顶向下地套。

### 7.3 落地口径：强度标注（已定）
- 引擎照常吐**各级所有坍缩信号**（候选买卖点）。
- 区间套作一个**独立的自顶向下 pass**，给每个信号标「嵌套深度 / 是否套住」。
- **可操作性交策略层**按深度门限决定——保全多假设、与「纯结构坍缩」一致，**划分**与**买卖点定级**分层。

## 8. 多义性处置与对两个原始问题的回答

### 8.1 第33课三种多义性的处置
| 多义类型 | 处置 |
|---|---|
| ① 级别延伸多义（节点②） | **消除**（延伸≤5 收敛） |
| ② 模本精度多义 | 天然接受，不处理 |
| ③ 实质多义（结合律重组） | **保留**，但作**只读视图**，不进 live 引擎 |

### 8.2 回答
- **已完成走势 → 中枢唯一确定**：live 分支（节点①②③）全是「会坍缩」的多义，走势一完成即坍缩成唯一一棵树。
- **未完成走势 → 按多样性划分**：live 收敛解（多假设并存、随走势坍缩）+ 第③种结合律的只读多角度视图。
