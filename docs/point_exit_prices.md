## 价格映射：系统推导

以下是系统对现有严格结构失效字段的解释，不声称原文规定了这些固定止损订单：

| 买卖点 | 止损参考 | 触发方向 |
| --- | --- | --- |
| 一买 / 一卖 | 一类转折的实际低点 / 高点 | 低于 / 高于 |
| 严格二买 / 二卖 | 所依赖的前一转折低点 / 高点 | 低于 / 高于 |
| 弱二买 / 二卖 | 当前回试转折的实际低点 / 高点 | 低于 / 高于 |
| 三买 / 三卖 | 所属中枢 ZG / ZD | 低于 / 高于 |

三类点回试恰好触及 ZG / ZD 仍符合当前程序规则；只有跌破 / 升破边界，才触发结构失效参考。第20课第427–436行的“不跌破 / 不升破”是原文措辞；把它映射到整数 tick 的严格不等式是程序实现。后续行情越界也不抹去历史上已确认的三类点。

一类点的初始止盈观察价为最后中枢 DD（买向）或 GG（卖向），而非 ZD / ZG；这是结构观察位，不是固定兑现价。只对同级趋势背驰生成该观察位，盘整背驰不能套用。二、三类点没有足够依据时显示“待同级反向点”，不使用固定涨幅、盈亏比或虚构未来中枢生成数值。

一类点的观察价现在还须通过同一比较中枢的身份核验：点、中枢和背驰的中枢 ID 相同，成立与首次可知时刻一致，且已确认点对应中枢实际冻结的背驰边界及锚定单元。错配时不生成 DD/GG 观察价，也不把该一类点用作其他点的反向退出参考。参考中保留比较中枢 ID 和可知时刻；这是程序的证据一致性检查，不是原文给出的下单规则。

原点确认之后，若其所属物理周期、结构层级、结构来源及价格口径均相同的反向点已经确认，则展示最先可识别的反向点及其确认时刻。该数值为后续确认的历史拐点价，不是入场时已知价、确认时成交价或保证盈利价。不会跳过不盈利的首个反向点去挑选更好看的后续点。卖点之后的价格用于反向风险与回补观察，不假设用户持有空头头寸。

“形成与等待”的点仅给出条件预案；其未完成结构变化时，参考价可变。5m 主信号和区间内 1m 确认点各用本级参考，1m 确认不会替换 5m 的退出级别。若5m已确认而1m尚缺确认，5m的独立价格参考不代表组合入场已经通过；此确认不等于第61课逐层背驰区间套。

## 因果与展示

- 原点、原中枢和保存证据保持原样，价格参考单独放在 `point_exit_plans` 中。
- 使用快照截止时刻之前可得的结构；后续反向点必须在原点可识别之后才出现拐点，并在快照截止前确认。
- 一类点的 DD / GG 根据原点时刻已知的中枢组成段冻结。之后的延伸不能倒写早先观察价；旧证据不能证明当时的区间时，保留缺失状态。
- 数值按原始整数 tick 与该快照价格精度转换，缺少精度或边界时不给伪造的0值。
- 选股页使用已经保存并通过校验的证据计算参考，不启动选股或重新构建结构。缓存按证据文件版本失效。
- 图表标记仍保留简短名称；详情标题和“买卖点止盈止损参考”折叠列表提供价格。选股页主信息显示该信号所属 K 线周期的参考价及原文位置。
