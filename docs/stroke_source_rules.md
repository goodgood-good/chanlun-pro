已从本次会话记录找回前面的完整答复，无须用户重新提供或确认规则。会话记录仅用于恢复已讨论的结论，不作为缠论原文来源。前面的最终核查明确更正过“删除 P、A、B，再向更早 Q、S 连续回退”的推导：当时尚未证明相邻性、分型取舍与完成边界，因此不能把它视为已经定稿的通用撤笔算法。

对已讨论的 `P 顶 → A 底 → B 顶 → C 底 → D 顶`，继续沿用以下结论：

| 已知条件 | 已核定的处理边界 |
| --- | --- |
| C 在 B 之后且 C 低于 A | C 不属于 A→B 的内部，不能仅据此否定 A→B 的区间极值。 |
| B→C 不够旧笔间隔 | 不连接 B→C；C 的价格仍参与以后跨过 C 的连接核验。 |
| 尝试 A→D，内部 C 低于 A | A→D 不满足起点最低要求，不能作原起点延伸。 |
| 尝试 P→C，内部 B 高于 P | P→C 不满足起点最高要求，不能直接延长前一下降连接。 |
| 后续 D 高于 B，D 之前没有底能与 B 成笔 | B 的后续接续需要重新审查，不能由此自动推出可撤去多少历史笔。 |
| 提出更早的 Q→D、S→C | 间隔和极值通过只是必要条件，还必须证明没有跨过应保留的笔，且允许修改相关末端。 |

这些是第 66 课作者回复的区间要求、第 62 课相邻要求、第 77 课取舍步骤以及第 69 课完成限制的联合推导，不是原文直接使用上述字母给出的公式。实现按这些已确认条件构笔；下一笔承接、当前端点重选和永久不可修改不混为同一概念，状态接口的工程含义见当前说明。
