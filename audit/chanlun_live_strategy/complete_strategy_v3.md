## 2. 冻结的操作者模式

### 2.1 适用画像

本版本只对应第79课中的“有时间观察、资金规模不大、固定操作级别、寻找第三类买点”的技术操作者：

```text
方向              = 只做多
战略方法          = 30分钟首中枢第三类买点轮动
短差方法          = 已持有战略仓中的5分钟中枢震荡
定位方法          = 1分钟第一/第二类点、背驰或盘整背驰
笔定义            = ORIGINAL_OLD_PEN（原始旧笔）
新笔口径          = 禁止
资金              = 无压力自有资金
融资与杠杆        = 禁止
零成本后增加股数  = 禁止
```

市场执行范围冻结为现金账户可做多的股票或交易型基金，不做空、不融资；默认面向存在T+1可卖限制的中国场内品种，具体取得日、可卖量、数量增量、税费和交易状态仍以券商运行时事实为准。若标的允许T+0，本版仍保守限制每标的每日最多一个完成短差周期；要提高频次必须另建参数版本并重新验证。

依据：L79 P1989—1991；L38 P1181；L44 P1313—1315；L26 P719、P756；L31 P949、P951—952。

### 2.2 不混用的模式

以下不属于 v3.0：

- 忙碌者的基金定投模式；
- 大资金长期固定标的、各级别全仓中枢震荡模式；
- 第16课“下跌—盘整—下跌”一买后见盘整即走的独立模式；
- 卖空、融资、追涨或无买点摊平。

### 2.3 多级别分仓的合法性

第38课允许不同数量按不同级别操作；第44课禁止用1分钟信号清掉30分钟仓位。因此初始战略买入成交后，立即按实际成交量划分：

```text
CORE_TARGET     = Q_CYCLE - TACTICAL_TARGET
TACTICAL_TARGET = floor_to_lot(Q_CYCLE * 0.25)
```

`CORE` 只服从30分钟战略层；`TACTICAL` 只服从5分钟短差层，并由1分钟定位。两者是账本标签，不是两个券商账户。30分钟战略退出可以处置全部股票；1分钟信号永远不能处置 `CORE`。

第79课“第三类买点后持股、到新中枢前中途不参与短差”约束L0战略数量；本文没有拿L0中枢上移本身做同级别差价。只有预先分出的 `TACTICAL` 数量，在L1自己的已完成中枢处于 `OSCILLATION` 时，才依据第38课“不同数量可按不同级别操作”和第73课“操作级别中枢上移无短差、中枢震荡才有短差”运行；L1一旦转 `UPMOVE`，普通短差立即关闭。因此小级别短差不是对L79持有规则的绕过。

## 3. 账户结构与组合调度

### 3.1 v3.0 参考参数集

以下是冻结的 `ENGINEERING` 参数，不冒充原文唯一数值：

```text
account_exposure_cap = 0.90
slot_count           = 5
slot_fraction        = 0.90 / 5 = 0.18
tactical_ratio       = 0.25
max_tactical_cycles_per_symbol_per_day_under_T1 = 1
liquidity_lookback_sessions = 20
max_order_fraction_of_median_daily_volume = 0.01
max_order_fraction_of_median_same_clock_L2_volume = 0.05
median_effective_spread_ticks_max = 2
valid_quote_coverage_min = 0.99
```

第31课只给出“针对每只股票留部分机动资金，例如1/10”的示例；本文把它固化为账户层90%新仓敞口上限、至少保留10%空间，是 `ENGINEERING` 转换，不声称原文规定全账户必须90/10。25%短差比例取第26课给不熟练者 `1/3或1/4` 的保守端。五个槽位以及流动性数值也都是 v3.0 的组合/执行工程裁决，变更必须产生新参数版本并重新验证。

### 3.2 计划数量与实际周期数量

入场前：

```text
U_SLOT        = account_equity_at_decision * 0.18
RESTORE_EXPOSURE_COMMITMENT
              = sum(每个待恢复批次remaining_qty
                    * max(当前有效原始价, 该批每股卖出毛额,
                          已活动恢复单的买入限价))
U_REMAIN      = max(0, account_equity_at_decision * 0.90
                       - current_gross_market_value
                       - RESTORE_EXPOSURE_COMMITMENT
                       - reserved_strategic_entry_notional)
TOTAL_PROTECTED_CASH
              = RESTORE_CASH_RESERVE
                + sum(max(0, 活动买单最坏所需现金
                              - 分配给该单的恢复现金准备))
ENTRY_CASH_AVAILABLE
              = max(0, broker_available_cash - TOTAL_PROTECTED_CASH)
BUY_PRICE_CAP = L2买点确认K线最高价
BUY_CASH_REQUIRED(q, p)
              = q*p + bound_buy_cost(q,p)
MAX_AFFORDABLE_BUY_QTY
              = 最大非负整手q，使 BUY_CASH_REQUIRED(q,BUY_PRICE_CAP)
                <= ENTRY_CASH_AVAILABLE
Q_LIQUIDITY_CAP
              = floor_to_lot(min(
                  0.01*最近20日已完成日原始成交量中位数,
                  0.05*最近20日同一时刻L2柱原始成交量中位数
                ))
Q_PLAN        = min(
                  floor_to_lot(U_SLOT / BUY_PRICE_CAP),
                  floor_to_lot(U_REMAIN / BUY_PRICE_CAP),
                  MAX_AFFORDABLE_BUY_QTY,
                  Q_LIQUIDITY_CAP
                )
```

`bound_buy_cost` 必须使用已绑定券商费用模型，并包含最低佣金、费用舍入和全部买方税费；不能用固定百分比近似。每张买单预留“限价名义金额＋该数量在限价下的最坏买入费用”，多张订单不能重复使用同一笔现金。恢复单可以使用其批次专用现金准备，不足部分才占一般可用现金；新战略入场永远不能使用恢复现金准备，也不能把待恢复量造成的敞口空位当成永久空位。若连一个交易单位及其费用都负担不起，`Q_PLAN=0`，不发单。

初始订单有效期结束后：

```text
Q_CYCLE = initial_entry_actual_filled_qty
```

- `Q_CYCLE == 0`：没有持仓，回到等待新结构；
- `Q_CYCLE > 0`：不追未成交部分，以实际成交量重新计算 `CORE_TARGET/TACTICAL_TARGET`；
- 整个战略周期内 `Q_CURRENT <= Q_CYCLE`；
- 战略满仓管理期间 `Q_CURRENT + pending_restore_qty == Q_CYCLE`；
- 战略周期关闭前不得通过交易增加 `Q_CYCLE`；送转、拆并股等强制公司行为按官方权益因子同步缩放全部数量字段，不属于加仓；
- 若 `TACTICAL_TARGET` 小于最小交易单位，自动关闭短差，只运行战略仓。

90%是新订单成交后的预交易上限，不因持仓自然上涨而强制再平衡；自然上涨使实际敞口超过90%时，只阻断后续新仓。每个证券最多占一个战略槽位。

新仓回撤门固定为：`drawdown=(session_close_equity_high_watermark-current_broker_equity)/session_close_equity_high_watermark`。高水位只在收盘后上调；盘中回撤达到或超过10%停止新入场，但不制造已有持仓的卖点。

为使该回撤和现金预留可审计，本版要求独立现金账户；`LIVE_ENABLED` 且存在开放周期时禁止人工入金、出金、转入/转出证券或账户外手工交易。确需变更资本，先停用新单、等待全部可放弃订单终态、保留持续退出、完成券商对账，再以变更后的权益建立新的高水位基准、参数快照和激活签名。公司行为到账不属于外部资本转移，按第10.1节处理。发现未登记转移立即 `OPERATIONS_HALT`，不能让入金掩盖回撤或让出金制造假回撤。

这解决了计划价格与真实成交价格不同、最低佣金令现金除法失真、以及部分成交后仍把计划数量当成满仓的问题。

### 3.3 跨标的唯一排序

多个候选同时出现时按下列顺序，不允许盘中临时讲故事：

1. 高周期风险门可买者优先；
2. 个股路径内，基本面角色 `LEADER` 优先于 `GROWTH_CHALLENGER`；基金代理路径跳过本项；
3. 个股路径内，比价状态 `UNDERVALUED` 优先于 `FAIR`；基金代理路径跳过本项；
4. 首中枢三买优先，其他中枢三买不属于本版；
5. 板块强弱值从高到低；
6. 战略三买 `confirmation_time` 从早到晚；
7. 同一确认时刻按证券代码字典序；
8. 已被有效订单占用的槽位视为不可用；
9. 可用现金不足一个完整槽位时，只按真实现金缩量，不借款、不挪用其他持仓槽位。

全局优先级不仅排序信号，也排序现金。已有标的的恢复现金准备先于任何新战略入场，短差买回意图也优先；需要时撤销尚未成交的低优先级入场单释放一般预留现金。所有买单仍只能使用其专用恢复准备与未预留一般现金，绝不融资。

## 5. 结构计算的唯一口径

### 5.1 已完成数据

- 只使用已经收盘的K线；
- 未完成端点标记为 `PROVISIONAL`，没有订单权限；
- 同时记录 `structure_end_time`、`confirmation_time`、`decision_time`；
- 重画只能产生新版本，不能覆盖信号当时快照。

原文允许高手用小级别提前处理尚未完全形成的高周期分型；v3.0 为排除未来函数，不把未收盘高周期K线记为已形成分型。若小级别买卖点本身已成立，只能以该小级别点的名义操作。

### 5.2 周期图与走势级别

默认观察窗口是 `30分钟/5分钟/1分钟`，但三者只有在递归结构上分别构成直接上下级时，才可登记为 `L0/L1/L2`。周期图不自动等于走势级别，依据 L63 P1759。

以下任一发生即禁止产生新订单：

```text
L0/L1/L2 不是直接递归关系
同一数据存在两个无法唯一裁决的线段划分
走势端点依赖未完成结构
中枢归属或扩展级别无法唯一判定
```

对持仓标的出现结构歧义时，禁止新增和普通短差，但已经确认的上级退出意图继续由订单层执行。

### 5.3 包含、分型、旧笔、线段

包含、分型和笔采用第62、77课正文中的原始旧笔口径；线段采用第67、71课的特征序列口径。新笔的放宽条件不进入本体系：

结构内核固定如下：

1. **价格归一**：所有高低价先换算为整数 tick；复权只用于结构连续序列，订单价格始终使用当时原始可交易价。
2. **包含关系**：相邻两根K线只要一根的 `[low,high]` 完全包含另一根就合并。方向向上时 `high=max(high1,high2), low=max(low1,low2)`；方向向下时 `high=min(high1,high2), low=min(low1,low2)`。方向由合并前最近两根无包含K线的高低点同向抬高/降低确定；序列开头方向未知时缓存，不产生结构信号。
3. **分型**：在处理后、无包含的连续三K线中，中间K线高低点均高于两侧为顶分型，均低于两侧为底分型。分型在第三根处理后K线收盘时确认。
4. **笔（只用原始旧笔）**：只连接时间相邻的异性质分型；两分型不能共用处理后K线，且两分型之间至少有一根不属于任何一端分型的独立处理后K线；顶分型最高K线与底分型最低K线还须有实际价格区间分离。相邻同性质候选出现时，顶保留更高者、底保留更低者；同价保留更早者，直到相反有效分型确认。
5. **线段**：至少三笔且起始三笔有重叠。每一条与当前线段方向相反的笔，以其高低区间作为原始特征元素；先像处理K线一样消除同一候选序列内的包含关系，得到标准特征序列，再找分型。向上笔开始的线段取标准化后的向下笔序列，只找顶分型；向下笔开始的线段反之。考察假设转折点时，旧序列最后一个特征元素与转折后第一个元素不能跨边界做包含合并；转折后的同性质元素之间仍可做包含处理。标准特征分型第一、二元素区间有重合即无缺口，无缺口时由分型极值确认原线段终点；无重合即有缺口，此时必须从该极值开始建立反向标准特征序列，等其出现相反分型才确认原终点。第二序列只要出现该分型即可，不再递归区分第一/第二种情况，也不要求先回补原缺口。
6. **完成权限**：线段终点只有在上述第一或第二种情况完成后冻结；此前端点是 `PROVISIONAL`，没有中枢、背驰或订单权限。冻结后不覆盖旧快照；若数据订正，只能生成新版本并触发对账停机。

完全相同K线按当前方向合并；合并高低点同价时，端点时间取最早原始K线、确认时间取最后参与合并K线的收盘。这里的同价时间选择是 `ENGINEERING` 审计规则，不改变价格结构。若实现不能唯一给出上述结果，执行 `NO_NEW_ORDER_KEEP_CONFIRMED_EXIT`，不得人工选择看起来更顺眼的划分。

旧笔的排他性判定如下，五项必须同时成立：

```text
pen_definition_mode                  = ORIGINAL_OLD_PEN
endpoint_fractal_types               = one_top_and_one_bottom
endpoint_fractals_share_processed_K  = false
independent_processed_K_between      >= 1
endpoint_price_interval_separation   = true
```

只要 `independent_processed_K_between = 0`，就判定 `NOT_A_PEN`，即使按未处理原始K线根数或其他新笔放宽方法能够连成笔也无效。全文的“笔破坏、向上笔、向下笔、三笔重叠、线段、中枢、背驰和买卖点”都只能消费这一旧笔序列；禁止某个级别、品种或行情软件单独切换为新笔。依据：L62 P1756—1757；L77 P1961—1967。

### 5.4 中枢对象

中枢由至少三个连续次级别走势类型的重叠形成。对初始三个区间：

```text
ZD = max(low_1, low_2, low_3)
ZG = min(high_1, high_2, high_3)
center_exists <=> ZD <= ZG
DD = min(low_i)   over all completed component/oscillation intervals assigned to this center version
GG = max(high_i)  over all completed component/oscillation intervals assigned to this center version
```

每个中枢必须保存：

```text
center_id
structural_level
first_three_component_ids
ZD/ZG
GG/DD
phase
version
confirmed_at
```

初始 `ZD/ZG` 冻结；延伸只更新围绕中枢波动的 `GG/DD`，不事后改写初始边界。

短差层对同一L1中枢统一记：

```text
A  = L1.ZD
B  = L1.ZG
Z  = (A+B)/2                       # 中枢中轴
Zn = (dn+gn)/2                     # 第n个已完成L2震荡区间的中点
```

其中 `[dn,gn]` 是第n个已完成L2震荡走势的实际区间。为避免半个tick被错误舍入，实现中保存 `2Z=A+B`、`2Zn=dn+gn` 的整数tick和，所有强弱比较都用交叉整数比较，不把Z或Zn四舍五入成可交易价格。A/B/Z/Zn及监视意义依据L92 P2199—2200；整数表示是 `ENGINEERING`。

### 5.5 中枢阶段

合法阶段只有：

```text
BUILDING
OSCILLATION
UP_RETURN_PENDING
DOWN_RETURN_PENDING
UPMOVE
DOWNMOVE
EXPANSION_RECLASSIFYING
```

转移规则：

- 完成前三段重叠：`BUILDING -> OSCILLATION`；
- 完整次级别向上离开：`OSCILLATION -> UP_RETURN_PENDING`；
- 第一次完整回试 `low >= ZG`：确认三买，转 `UPMOVE`；
- 回试低点 `< ZG` 而重新进入中枢：原中枢延伸，回 `OSCILLATION`，沿用原 `center_id/ZD/ZG`；
- 向下完全反向处理；
- 出现同级别中枢重叠、次级别升级或不能再维持原级别唯一划分：转 `EXPANSION_RECLASSIFYING`；
- 已确认三买/三卖后，在新同级别中枢尚未完成前又返回旧中枢：也转 `EXPANSION_RECLASSIFYING`，不得继续把旧标签当单边走势使用；
- 重分类完成后生成新 `center_id/version`，再进入 `OSCILLATION/UPMOVE/DOWNMOVE` 中唯一一种。

`Zn` 越过 `A/B` 只有警报权；它本身不等于三买、三卖，也不自动等于扩展。依据 L92 P2199—2200。

### 5.6 三类点边界

本版直接遵守第20课“不跌破/不升破”的包含等号定义：

```text
第三类买点：first_return_low  >= ZG
第三类卖点：first_return_high <= ZD
买点回试 low < ZG、卖点回抽 high > ZD：重新进入中枢，按延伸或后续扩展分类
```

价格先按交易所最小变动单位归一再比较，不使用浮点近似容差，也不把等号改写成工程裁决。

### 5.7 第一、第二类点与背驰

- 第一类买点：一个已完成同级别下跌趋势至少有两个依次下移中枢；最后中枢前后的两段同向离开段由结构先选定，后一段创新低而力度严格小于前段，趋势背驰终点确认。第一类卖点完全反向。
- 盘整背驰：同一中枢前后、同方向且同级别的震荡段由结构先选定；后一段越出相应边界而力度严格小于前一可比段。它只在原文允许的盘整买卖点位置使用，不能冒充需要两个中枢的趋势背驰。
- 第二类买点：第一类买点后的第一次完整次级别上升结束，再一次完整次级别回试的低点 `>=` 第一类买点低点；回试结束由更低一级买点定位。第二类卖点反向，反抽高点 `<=` 第一类卖点高点。
- 小级别转大级别导致本观察级别没有可及时确认的一买时，不追转折；等待上述本级别二买。

力度的 v3.0 唯一计算口径是保守的“结构候选 + MACD确认”：

```text
DIF = EMA(close,12) - EMA(close,26)
DEA = EMA(DIF,9)
HIST = 2 * (DIF-DEA)
up_strength(segment)   = sum(max(HIST,0)) over segment bars
down_strength(segment) = sum(abs(min(HIST,0))) over segment bars
divergence             = later price makes required new extreme
                         and later same-direction strength < earlier strength
```

EMA 从运行时可得的最早连续历史以首个收盘价初始化，信号前至少预热 `5*26=130` 根本观察窗口K线。MACD不能自行挑选比较段；比较段必须先由中枢与走势类型确定。任一段未完成、级别不同、历史不足、面积相等、价格未创新极值或划分有歧义，登记 `DIVERGENCE_UNCERTAIN`，不得用该背驰产生新单。这个数值化是 `ENGINEERING` 的保守确认子集，不宣称 MACD 面积就是原文“力度”的唯一数学定义。

战略三买回试末端允许以下任一定位确认：

```text
L2_FIRST_BUY
L2_SECOND_BUY_AFTER_SMALL_TO_LARGE_REVERSAL
```

第二种必须保存小级别转大级别的反转低点、第一段完整L2上升和随后不创新低的完整L2回试；缺少任一对象就不是二买。这补齐了“没有本级别一买时等二买”的原文分支。

## 6. 上游选股系统

### 6.0 三个独立程序的组合

原文边界：第9课要求不要堆叠同源技术指标，而应把技术、比价/资金关系和基本面等相对独立程序组合；第72课说明基本面与比价关系决定介入种类，介入后技术面在操作上起决定作用；第73课把比价关系明确为“市值与行业地位的关系”，并给出龙头与成长企业的组合思路。依据 L9 P42—43、L72 P1912、L73 P1924。

本版以 `ENGINEERING` 方式把它落实为月度及重大正式信息事件后的点时研究快照：

| 独立程序 | 允许状态 | 必须记录 | 权限 |
|---|---|---|---|
| 基本面 | `LEADER / GROWTH_CHALLENGER / REJECT / UNRESOLVED` | 行业长期空间判断、公司行业地位判断、当时可见正式披露文件 ID、有效时刻、签名 | 只决定个股是否进入技术候选，不直接买卖 |
| 比价关系 | `UNDERVALUED / FAIR / OVERVALUED / UNRESOLVED` | 点时总市值、同业集合、基本面行业地位、判断与签名 | 只过滤和排序，不直接买卖 |
| 技术面 | 本文定义的市场门、板块、结构和买卖点 | 当时结构快照与确认时间 | 正常持续交易条件下的唯一最终买卖权；仅有L26交易延续性生存退出例外 |

非技术状态只按下列语义签署，不添加本文之外的财务公式：

- `industry_opportunity_status=PASS`：依据决策时已正式公开资料，研究者明确判断该行业具备原文所说的长期发展空间；`REJECT` 表示明确不具备，`UNRESOLVED` 表示证据不足或互相冲突；
- `LEADER`：研究快照认定为当时行业龙头；`GROWTH_CHALLENGER`：认定为有可能在以后超越当时龙头的成长企业；其余为 `REJECT/UNRESOLVED`；
- `UNDERVALUED`：在冻结的点时同业集合中，总市值相对于已签署的行业地位被判断为低估；`FAIR` 表示未判低估、也未判高估，`OVERVALUED` 表示高估，无法形成明确结论为 `UNRESOLVED`；
- 每个判断必须带原始正式披露ID、点时同业集合、当时总市值、有效时刻和复核签名；不得看到技术信号后倒填、回溯修改或用后续资料覆盖旧快照。

个股路径必须同时满足：行业长期机会为 `PASS`，基本面为 `LEADER` 或 `GROWTH_CHALLENGER`，比价为 `UNDERVALUED` 或 `FAIR`，然后再通过全部技术门。任一非技术程序过期或 `UNRESOLVED`，禁止新开该个股；不能拿技术强势替代缺失的独立研究，也不能拿基本面优秀提前买入。基本面或行业地位改变本身不直接卖出：原文要求介入后由技术面决定操作；换股只在原持仓出现完成的上级别技术卖点后，再等待新候选自己的技术买点。

允许 `FAIR`、拒绝 `OVERVALUED` 并把 `UNDERVALUED` 排在前面，是为了把原文“关注市值—行业地位并发现低估品种”冻结成可执行集合的 `ENGINEERING` 裁决；原文没有给出“合理/低估”的数值分界，也没有说所有龙头都必须已被判为低估。该状态必须由独立研究签名，不能由价格走势反推。

“行业空间、龙头、成长、低估”原文只给原则而无唯一公式，所以本文不伪造财务阈值。若操作者没有能力形成独立、点时、可审计的研究快照，个股路径关闭；按第72课的简化方法，只允许转为当时可交易的宽基或行业基金代理，仍必须等待本文技术买点，不能直接买基金。`INDIVIDUAL_THREE_PROGRAM` 与 `ETF_PROXY` 是同一参数快照中互斥的激活路径，不能为挑中事后赢家而盘中混用；切换路径必须产生新参数快照并重新走验收。大型资金示例中的70%龙头/30%成长不适用于本版五槽小资金画像，本版仍按18%槽位与90%总敞口执行。

### 6.1 可交易池

从运行时全部可做多标的开始，排除：

- 停牌或没有可靠连续行情；
- 无法读取最小交易单位、价格边界或费用；
- 结构历史不足以形成并验证一个L0中枢；
- 流动性不足以在历史模拟中按本订单规则成交；
- 可能无法延续交易且退出机制无法执行的标的。

可交易性只有否决权，不能制造买点。

第26课把“交易能否延续、交易是否算数”列为理论之外必须首先提防的风险（L26 P718）。因此，持仓后若交易所或券商正式确认标的将终止正常交易，且存在最后可执行窗口，产生 `STRATEGIC_EXIT_INTENT(reason=TRADING_CONTINUITY_LOST)`：取消全部买单和短差、终止恢复义务，在最早合法机会持续全退。它是原文明确风险边界触发的生存处置，不是基本面卖点，也不能由传闻、媒体猜测或研究员判断触发；状态不确定时先 `OPERATIONS_HALT` 核实。普通停牌但恢复交易安排明确，不等于永久失去延续性，仍按持续退出阻塞规则等待。

流动性口径固定为仅使用决策前20个已完成交易日的原始成交量和报价：计划中的每张可放弃订单不得超过“日成交量中位数的1%”与“同一交易时段内相同L2柱序号成交量中位数的5%”两者较小值。报价统计网格取这20日连续竞价中每根已完成L2柱的结束时刻，使用结束时刻之前、且未超过数据SLA的最后一笔正常最优报价；`bid>0、ask>=bid` 才有效，覆盖率为有效网格数/应有网格数，必须至少99%。本文字段名“中位有效价差”明确计算为 `median((best_ask-best_bid)/price_tick)`，即有效最优报价的可执行盘口价差，不采用未定义的其他微观结构含义，且不得超过2 tick；当前决策报价也必须有效且新鲜。不足20日、报价覆盖不足或任一统计不可复现时标为 `UNRESOLVED`，禁止新战略单和所有可放弃短差单。持续风险退出不受此数量上限阻断。

这些20日、1%、5%、99%和2 tick都是 `ENGINEERING` 执行参数，不是缠论原文给出的数值；其作用只是防止同一结构信号在回放中假定能成交、真仓中却因自身订单规模而失真。

历史回放不能拿今天的股票列表倒推过去；每个决策日必须使用当时的证券主数据，并保留后来退市、长期停牌或更名的标的。任何单标的“执行适配”只能用决策时点以前的数据或激活前已冻结的独立验证结果，不能看到该笔交易之后才决定它是否进入样本。

### 6.2 高周期风险门

高周期优先级冻结为：

```text
月 > 周 > 日
```

同一状态机分别运行在宽基市场基准、点时板块代理和个股上；`market_gate` 只由宽基基准生成，板块和个股风险作为各自候选门，三者不能混成一个标签。

每个周期的分型状态：

```text
NONE
FORMED
FORMED_UNRESOLVED
PEN_RISK_CONFIRMED
INTERMEDIATE
RESOLVED_CONTINUATION
```

顶分型只有辅助意义。`PEN_RISK_CONFIRMED` 表示对应最大可唯一识别小级别中枢出现三卖且未扩展，或粗模式下有效跌破5周期线；它不表示未来收益得到保证。

对应小级别中枢的原文原则是“分型区间内选择最大的一个”。为使程序唯一化，v3.0 的 `ENGINEERING` 映射规则是：在高周期三根分型K线覆盖的时间区间内，选择包含形成该分型之第一/第二类点的、最高且唯一完成的小级别中枢。无法唯一映射时状态为 `FORMED_UNRESOLVED`，阻断新仓。

顶分型风险按以下事件推进：

```text
NONE
  ├─ 完成顶分型且映射唯一 ─> FORMED
  └─ 完成顶分型但映射不唯一 -> FORMED_UNRESOLVED
FORMED_UNRESOLVED ─ 映射后来唯一化 -> FORMED
FORMED
  ├─ 对应中枢三卖且未扩展 -> PEN_RISK_CONFIRMED
  ├─ 三卖后形成中枢扩展并出现相应小级别底背驰买点 -> INTERMEDIATE
  └─ 对应中枢三买确认 -> RESOLVED_CONTINUATION
PEN_RISK_CONFIRMED ─ 高周期向下笔由相反分型完成 -> NONE
INTERMEDIATE/RESOLVED_CONTINUATION ─ 新顶分型出现 -> 重新建立本轮风险事件
```

`INTERMEDIATE` 表示已按小级别结构确认是中继并出现可恢复点；`RESOLVED_CONTINUATION` 表示对应小级别三买已确认。二者都解除旧顶分型对新仓的阻断，但它们本身仍没有下单权。底分型采用完全反向的结构记录，只提高候选观察顺序；真正买入仍须本体系的战略买点。

新战略多仓门：

- 任一更高周期 `PEN_RISK_CONFIRMED`：`RED`，禁止新仓；
- 任一周期 `FORMED/FORMED_UNRESOLVED`：`AMBER`，禁止新仓；
- 所有顶部风险已解决或不存在：`GREEN`；
- 底分型只提高观察顺序，不能直接买入。

依据：L79 P1994—1997；L82 P2053—2058；L106 P2464—2465。

### 6.3 板块横向强弱

采用第106课候选均线组：

```text
5, 13, 21, 34, 55, 89, 144, 233
```

工程定义：

- 反弹锚点对同一市场的所有板块和成员必须共用：取其宽基基准最近一次可唯一确认的日底分型第三根K线收盘时刻，等价的已确认日向上笔起点只用于校验；不能给每只股票挑不同起点。无法唯一确定共同锚点时，全部板块强弱为 `UNRESOLVED`；锚点后上市的成员从首个已完成交易日开始观察，仍按下面的短历史规则保留在分母；
- “攻克均线”定义为从反弹锚点开始，曾有任一已完成日K收盘站上；不是只看决策日当前收盘；
- 第一条未攻克均线的序号为类别1—8，全部攻克为9；
- 板块强弱是点时成分股类别的等权平均；
- 停牌成员使用决策时点最后一根已完成日K；正式上市历史完整、只是交易日数短于某条均线的新股，把第一条尚不可计算的均线视为“未攻克”（少于5个已完成日则类别1），仍留在点时成员分母中；
- 只有无法由上市日、停牌或官方交易日历解释的数据断档，才把整个板块强弱标为 `UNRESOLVED` 并阻断候选；任何情形都不得删除困难成员来抬高均值；
- 板块指标只有扫描排序权，没有订单权。

基金代理使用同一篮子强弱口径：行业基金按其点时跟踪篮子成分计算；宽基基金按其点时指数成分计算并标记 `BROAD_BASKET_STRENGTH`。它仍只有排序权。若基金跟踪标的、点时成分或权威映射不可得，则该基金为 `UNRESOLVED`，不能用“宽基没有板块”跳过强弱数据门。

### 6.4 最后一个L0中枢分类

```text
IN_CENTER                  -> WAIT
BELOW_WITHOUT_THIRD_SELL   -> WAIT
BELOW_AFTER_THIRD_SELL     -> REJECT
ABOVE_WITHOUT_THIRD_BUY    -> WAIT
FRESH_FIRST_CENTER_3B      -> CONTINUE_ENTRY_CHECK
```

这里的 `FRESH_FIRST_CENTER_3B` 只在第8.2节那次第一次完整回试确认后成立；`CONTINUE_ENTRY_CHECK` 表示把同一不可变快照交给其余账户、风险、递归和订单门检查，不表示已经成交，也不是提前于三买注册候选。首中枢形成以前可以进入观察池，但不占战略槽位、不预留现金。

依据：L49 P1454—1456、P1458—1459。

### 6.5 最终候选门

必须全部成立：

1. 独立选股路径已解决：个股具备有效行业机会、基本面与比价快照，或明确使用基金代理路径；
2. 个股行业长期机会为 `PASS`、基本面为 `LEADER/GROWTH_CHALLENGER`、比价为 `UNDERVALUED/FAIR`；基金代理记为 `ETF_PROXY`；
3. 高周期门为 `GREEN`；
4. 个股板块强弱或基金跟踪篮子强弱已按点时成分计算；
5. 板块和个股无未解决顶分型风险；
6. L0/L1/L2级别唯一；
7. 是新一轮L0向上结构的第一个完成中枢；
8. 尚未使用未来K线；
9. 账户有未被订单占用的战略槽位；
10. 账户回撤低于10%的新开仓暂停线。

上述门在第8.2节三买确认时必须重新同时计算；此前的观察池资格不能锁定市场颜色、研究结论、槽位或现金。实际买单仍只能由第8节战略三买触发。

## 7. 5周期均线的权限

默认模式固定为 `STRUCTURAL`：

- 5日/5周/5月线是低精度持有参考；
- 用于辅助观察高周期分型是否可能延伸成笔；
- 不产生战略买单；
- 不产生普通短差买卖单；
- 精确小级别买卖点、三买、三卖和背驰优先。

5日/周/月线均以 `ENGINEERING` 计算口径定义为对应周期最近5根已完成、按决策时点已知因子调整的收盘价算术平均；不足5根时为 `UNRESOLVED`。板块九分类中的全部均线也使用相同的简单算术平均口径，只是周期数不同。

`FRACTAL_MA_COARSE=false` 在 v3.0 固定关闭，因此“顶分型 + 有效跌破5周期线”只登记风险，不直接清仓。若未来开启，必须建立新策略版本，而不能持仓中途改变。这样是在原文明确区分的“低手5周期线模式”和“中高手小级别精确模式”中，只选择后一种，避免两套退出规则互相抢单。

原文对“有效跌破”的核心定义是“跌破后反抽上不来，并且反抽要与相应级别对应”。v3.0 的 `ENGINEERING` 可计算标签冻结为：一根已完成高周期K线收盘低于其当时MA5后进入等待；随后对应小级别反抽完成，以其**完成时刻所在的第一根高周期K线**为判定柱——反抽可以从更早的高周期柱开始，不要求整个反抽都落在同一根柱内。只有判定柱本身也完成，且收盘仍低于该柱同时点MA5，才标记有效跌破；若收回MA5及以上，本轮失败并复位，必须等待新的高周期收盘跌破重新开始。盘中刺破、反抽未完成、判定柱未收盘或一直没有对应反抽都不算。月线因此至少等待相应后续月份，符合原文示例。依据 L67 P1845；L79 P1994—1997。

## 8. 战略状态机

### 8.1 合法状态

```text
S_FLAT
S_WAIT_CENTER
S_WAIT_DEPARTURE
S_WAIT_RETURN
S_ENTRY_READY
S_ENTRY_WORKING
S_ACTIVE_FULL
S_REDUCE_WORKING
S_ACTIVE_HALF
S_EXIT_WORKING
S_CLOSED
```

状态变化必须由事件触发；报单不等于成交。

### 8.2 首中枢三买入场

在 `S_WAIT_RETURN` 中全部成立：

1. L0首中枢完成并冻结；
2. 一个完整L1向上走势离开；
3. 随后的第一次完整L1向下回试已结束；
4. `return_low >= ZG0`；
5. 回试末端确认 `L2_FIRST_BUY` 或允许的L2二买；
6. 市场门仍为 `GREEN`；
7. 没有更高优先级退出、数据故障或账户故障。

同一结构快照的最后L0中枢分类必须为 `FRESH_FIRST_CENTER_3B`；否则不得输出入场意图。

输出 `ENTRY_INTENT`，进入 `S_ENTRY_READY`。随后按第11节生成限价买单：

```text
BUY_PRICE_CAP = L2确认K线最高价
TTL           = 下一根L2 K线收盘或当前连续竞价时段结束孰先
```

第一笔可成交报价高于上限，或有效期内零成交：取消，不追，回到等待新结构。部分成交后取消剩余，以实际成交量建立 `Q_CYCLE`，进入 `S_ACTIVE_FULL`。

三买完成但市场门已不是 `GREEN`，不得把信号留到以后补买，直接作废并等待新结构。意图生成后、券商接受前风险门丢失，同样撤销。若入场工作单尚未关闭便出现战略全退信号：先撤余单；已有成交则以实际成交量建立 `Q_CYCLE` 并立即转持续退出，零成交则释放槽位。

这里没有“回试尚未冻结后的三买失败退出”；因为 v3.0 只在完整回试确认后买入。

依据：L20 P434；L49 P1454—1456、P1458—1460；L79 P1989；L26 P756。

### 8.3 战略退出优先级

从高到低，只执行第一项：

1. `TRADING_CONTINUITY_LOST`：正式交易延续性丧失，全部退出；
2. `L0_THIRD_SELL`：全部退出；
3. `FIRST_UP_LEG_FAILED`：三买后第一段完整L1上涨不能突破离开段高点，或相对离开段盘整顶背驰，全部退出；
4. `SECOND_SELL_CONFIRM`：已经减半后，完整L1下跌之后的完整L1上涨不创新高或盘整顶背驰，全部退出；
5. `L0_UPMOVE_DIVERGENCE`：满仓状态下L0中枢上移出现背驰；若 `floor_to_lot(Q_CYCLE*0.50)` 至少为一个合法持仓/卖出单位则减至该数，否则直接持续全退，绝不进入零仓的 `S_ACTIVE_HALF`；
6. 其余：按战略状态持有。

战略卖出意图一经确认：

- 取消全部未成交买单；
- 禁止普通短差；
- 立即把 `pending_restore_qty` 转入 `terminated_restore_qty`、将其归零，并把现有股票统一转为战略退出库存；此后不得再回补；
- 不以成本价、短差盈亏或市场门颜色撤销；
- 按真实可卖量执行；未卖部分进入持续退出订单，直到成交或出现券商明确不可交易状态。

依据：L26 P718；L79 P1989；L45 P1333。交易延续性事件的正式数据源、最后交易窗口和执行映射属于 `RUNTIME_FACT/ENGINEERING`。

### 8.4 半仓后的完整分支

战略减仓意图确认时即终止短差回补义务：`pending_restore_qty` 转存到审计字段 `terminated_restore_qty` 后归零，现有股票统一纳入战略减仓。减仓订单达到目标后进入 `S_ACTIVE_HALF`，短差目标清零，剩余股票全部标记为 `CORE_REMAINDER`。

减仓尚未达到半仓目标时若出现更高优先级的战略全退条件，原 `intent_id` 关闭为“升级”，立即建立全退意图并进入 `S_EXIT_WORKING`；不得先完成半仓再等待下一次信号。若成交越过半仓目标，接受真实结果，不反向买回纠偏。

后续：

- 下一完整L1下跌后，下一完整L1上涨不创新高或盘整顶背驰：全部退出；
- 下一完整L1上涨创新高且不背驰：保持半仓，重置“下跌—上涨”监视对，继续等待新的L0背驰或L0三卖；
- v3.0 不执行原文允许的该L1下跌回补，这是小资金轮动模式的保守工程裁决；
- 不得因为剩余半仓没有立即卖点而恢复短差或擅自加回满仓。

这样不会出现 `S_HALF` 没有下一状态的死分支。

## 9. 短差结构、库存与结算

短差不再使用一个枚举同时表示结构、库存、T+1和订单。四者独立记录。

### 9.1 结构阶段

使用第5.5节中枢阶段。

只有 `OSCILLATION` 允许普通短差；`UPMOVE/DOWNMOVE/EXPANSION_RECLASSIFYING` 禁止普通短差。

### 9.2 数量账本

```text
tactical_target_qty
tactical_held_qty
pending_restore_qty
tactical_restore_cohorts[]
pending_restore_gross_cash
pending_restore_allocated_sell_cost
restore_cash_reserve
restore_exposure_commitment
tactical_locked_qty
tactical_eligible_qty
terminated_restore_qty
```

在 `S_ACTIVE_FULL` 且无战略订单时必须满足：

```text
tactical_held_qty + pending_restore_qty = tactical_target_qty
Q_CURRENT + pending_restore_qty = Q_CYCLE
Q_CURRENT = core_held_qty + tactical_held_qty
0 <= tactical_locked_qty <= tactical_held_qty
0 <= tactical_eligible_qty <= tactical_held_qty
```

每个真实短差卖出成交建立一个不可变恢复批次：

```text
restore_cohort_id
sell_execution_id
open_qty / remaining_qty
gross_sell_cash
allocated_sell_cost
cash_reserve_remaining
sell_exchange_time
```

回补按 `sell_exchange_time, sell_execution_id` 的 FIFO 顺序冲销批次。卖出成交归属的券商实际净现金立即进入该批次 `cash_reserve_remaining`；费用未终态时按券商已实际计入的现金信用保守预留，终态后再精确分摊。账户级 `RESTORE_CASH_RESERVE` 等于全部开放批次现金准备之和。批次被部分冲销时，原批次的卖出现金、已分摊卖出费用、现金准备和失去的现金分配按本次冲销数量占原批次数量的比例实现，舍入尾差留到该批次最后一次冲销；买入真实支出少于被解除准备的差额才成为已实现、可释放现金，多出的支出只能来自未预留一般现金。只有这种逐批现金账，才能在部分成交、不同卖价和最低佣金并存时准确计算“买回后真实净差”；禁止用一个平均卖价替代真实现金。

卖单终态后，以券商实际订单总费用按各成交毛额比例分摊，舍入尾差全部给最后一个成交批次；此前批次费用是 `PROVISIONAL`，不能触发普通回补。买回费用在买单终态后结算。若真实计费与已绑定券商费用模型不一致，记录差异并执行 `OPERATIONS_HALT_CANCEL_BUYS`，不得为了让短差看起来盈利而改费用。

任何短差卖出真实成交：

```text
tactical_held_qty  -= fill_qty
pending_restore_qty += fill_qty
```

任何短差回补真实成交：

```text
tactical_held_qty  += fill_qty
pending_restore_qty -= fill_qty
```

战略退出或减仓意图确认时，短差恢复批次转为已终止审计记录，`pending_restore_qty` 立即归零，专用恢复现金准备转回一般现金；不能在战略风险动作之后继续回补。战略减半完成或周期关闭时，短差目标归零。

### 9.3 启用门

普通短差必须全部满足：

1. `strategic_state == S_ACTIVE_FULL`；
2. `Q_CURRENT + pending_restore_qty == Q_CYCLE`；
3. `tactical_target_qty` 至少一个交易单位；
4. L1中枢已经完成，阶段为 `OSCILLATION`；
5. L2结构唯一；
6. 无活动订单、无数据或账户故障；
7. 当日周期数未超限；
8. 历史短差适配度门已通过。

短差适配度使用决策时已经完成的最近20个L1震荡“卖点—下一买点”结构配对；至少已有5个完整配对。对每个配对，取该时点买入与普通卖出增量的最小共同合法数量 `q_eval`，按第11.5节的冻结延迟、严格穿价、真实点时费用、现金分配和公司行为逐事件模拟两腿：

```text
net_edge_ticks_i = (实际模拟卖出现金 - 卖出费用
                    - 实际模拟买入现金 - 买入费用
                    - 失去的现金分配)
                   / (q_eval * 当时price_tick)
```

任一腿无法成交的完整结构配对仍留在样本中，并按低于所有有限数的 `NON_EXECUTABLE` 排序，不能删掉来美化结果。中位数取排序后第 `floor((n-1)/2)+1` 个，即偶数样本也取较低的中间值，不做两数平均。只有该中位数为有限值且 `>= 1.0 tick`，适配门才通过；不足5个完整配对为 `UNRESOLVED`。这只是启用门，当前每张普通回补单仍必须另过第9.5节“每个可能累计部分成交前缀”成本检查。

依据 L38 P1181 的历史震荡幅度思路；20、5、最小共同数量、未成交惩罚、较低中位数和1 tick阈值均为 v3.0 `ENGINEERING` 参数。

### 9.4 普通短差卖出

必须全部满足：

1. L1仍为 `OSCILLATION`；
2. `pending_restore_qty == 0`；
3. 完整L2向上走势到达中枢中轴以上，优先在 `B` 上方；
4. 出现L2顶背驰、盘整顶背驰、第一类或第二类卖点；
5. L1三买未确认；
6. 实际可卖短差量大于0；
7. 历史适配度门通过；
8. 无战略卖出意图。

实际数量：

```text
sell_qty = floor_to_lot(min(
  tactical_held_qty,
  tactical_eligible_qty,
  broker_eligible_qty,
  Q_LIQUIDITY_CAP
))
```

普通卖单是可放弃的优化单：第一可成交报价若低于L2卖点确认K线最低价，则取消，不向下追卖。有效期为一根L2 K线；实际成交多少，只增加多少 `pending_restore_qty`。

依据：L49 P1459—1460；L59 P1711；L89 P2148；L105 P2433。

### 9.5 普通回补

必须全部满足：

1. `pending_restore_qty > 0`；
2. L1三卖未确认；
3. L1阶段仍为 `OSCILLATION`；
4. 完整L2向下走势到达中枢中轴以下或向下离开；
5. 出现L2底背驰、盘整底背驰、第一类或第二类买点；
6. 当前 `Zn >= A`；
7. 高周期政策允许普通回补；
8. 按最坏限价计算，订单可能出现的每一个非零累计部分成交前缀都至少覆盖真实往返费用并多一个价格跳动现金值。

普通回补最高限价：

```text
edge(f,p) = FIFO前f股对应卖出现金
            - FIFO前f股对应已分摊卖出费用
            - FIFO前f股对应失去的现金分配
            - f*p
            - bound_terminal_buy_cost(f,p)
            - price_tick*f

profit_cap = 最高合法tick价格p，使订单允许的每个非零累计部分成交量f
             都满足 edge(f,p) >= 0

buy_limit_cap = min(L2买点确认K线最高价, profit_cap)
```

报价高于上限则本次不回补，继续等待新的有效买点或L1三买保护。不能因为成本价而无买点追入。

若回补数量跨越多个恢复批次，先逐批计算可覆盖数量，只允许合并那些在同一买入限价下、对每个允许的累计部分成交前缀都满足净差门的连续 FIFO 批次；再取该数量、`Q_LIQUIDITY_CAP` 与计入最坏买入费用后的未预留现金可负担量之最小值，其余批次保持待恢复。`bound_terminal_buy_cost(f,p)` 必须按“订单最终只成交f、余量到期撤销”计算最低佣金和舍入；不能假设整单全成后再摊薄费用，也不能线性假定。若最小可能成交量都不满足，整张普通回补单禁止发出。

`Zn < A` 的硬阻断是 v3.0 的保守工程裁决；原文只说风险很大。必须在回放中单独统计其漏买率。

### 9.6 L1三买保护

完整L1向上离开后，第一次完整L2回试 `low >= B`，确认L1三买：

- `pending_restore_qty > 0`：产生保护性回补意图；
- 数量为待恢复量、`Q_LIQUIDITY_CAP` 与未预留现金在买入上限下可买量的最小者，不借款；
- 不要求该批短差为正；
- 买入上限为L2三买确认K线最高价；
- 有效期一根L2 K线；部分成交只减少实际成交数量；
- 未成交余量保持 `pending_restore_qty`，标记 `MISSED_PROTECTIVE_REBUY`；
- 此后没有新的有效买点不得追价；
- L1阶段转 `UPMOVE`，直到新L1中枢完成。

依据：L33 P1074；L73 P1922；追价禁令见 L26 P756。

### 9.7 L1三卖停止回补

完整L1向下离开后，第一次完整L2反抽 `high <= A`，确认L1三卖：

- 已有待回补量：保留数量但停止普通回补；
- 仍持有短差股票：发出短差风险卖单；每个真实卖出成交都增加 `pending_restore_qty`；
- 风险卖单不受普通卖单价格底线和净差要求限制；
- `CORE` 仍只服从战略状态；
- L1阶段转 `DOWNMOVE`；
- 只有三卖引发的L1下跌完成后的L1第一/第二类买点，或新完成L1中枢的三买，才可恢复；用L2定位；
- 战略卖出先发生时，终止全部恢复义务。

依据：L49 P1459；L59 P1711；L86 P2100—2103。

### 9.8 三卖后恢复买回

L1三卖后不再适用原中枢内的普通回补。只有下列新买点之一完成，才重新产生恢复意图：

1. 包含该三卖的L1下跌走势完成并确认L1第一类买点，用L2区间套定位；
2. 第一类买点后的L1回试不破前低，确认L1第二类买点，用L2定位；
3. 新L1中枢完成后的L1第三类买点；第三种仍走第9.6节保护规则。

前两种由 `T05 THIRD_SELL_RECOVERY` 执行：

- `pending_restore_qty > 0`，且没有战略退出或减仓意图；
- 大盘 `RED` 或个股高级别顶风险时暂停前两种恢复，只保留新L1三买保护；
- 不要求恢复批次盈利，因为这是三卖后新L1买点的仓位恢复，不是普通震荡差价；
- 数量仍受 `Q_LIQUIDITY_CAP` 和未预留可用现金限制；高优先级恢复可撤销尚未成交的战略入场单释放预留，但不能超过 `Q_CYCLE`；
- 买入上限为L2定位确认K线最高价，有效期到下一根L2 K线收盘或当前连续竞价时段结束孰先；
- 部分成交只冲销实际数量；第一类买点错过后只能等第二类买点，第二类买点也错过后只能等新中枢三买，禁止追价。

这补上了“停止回补”之后的恢复路径；否则系统会永久持有现金而没有合法返回状态。依据：L49 P1459；L59 P1711；L86 P2100—2103。

### 9.9 中枢延伸与扩展

- 离开后重新进入原中枢：认定原中枢延伸，完成分类后恢复原 `center_id/A/B`；
- `Zn` 越界但三类点未确认：只暂停到本次次级别走势完成并分类；
- 真正发生级别扩展：进入 `EXPANSION_RECLASSIFYING`，普通订单全部暂停；
- 重分类后，根据真实库存和待恢复数量进入新中心的“持股可卖”或“现金待买”条件，不使用 `READY_OR_CASH` 之类伪状态。

### 9.10 高周期冲突的冻结裁决

```text
market_RED_existing_position_policy = FOLLOW_SYMBOL_STRATEGIC_STRUCTURE
market_RED_pending_restore_policy   = ALLOW_ONLY_CONFIRMED_L1_THIRD_BUY
stock_top_pen_risk_policy           = BLOCK_ORDINARY_BUYBACK_ALLOW_L1_THIRD_BUY
```

即：指数风险不替代持仓个股30分钟卖点；市场或个股高周期风险阻断普通回补，但允许已经确认的L1三买保护，前提是没有战略卖出意图。该裁决牺牲部分风险回避，换取不因指数背景丢失已经卖出的短差筹码；它是工程选择，不是原文唯一答案。

## 10. T+1与批次账本

券商返回的每批股票必须记录取得日期和真实可卖量。

若运行时市场不允许当日买入后卖出：

- 初始战略买入当日不做短差卖出；
- 只卖逻辑上属于 `TACTICAL` 且券商确认可卖的数量；
- 当日回补量进入 `tactical_locked_qty`；
- 同标的当日最多一个“卖出—回补”周期；
- 下一交易日不能机械转为“可短差”，必须重新检查战略状态、中枢阶段、待恢复量和券商可卖量；
- 战略卖点被T+1阻挡时，状态保持 `S_EXIT_WORKING`，记录未退出数量，并在每个可执行机会继续；
- 不得卖出可卖的 `CORE` 冒充被锁定的 `TACTICAL`。

依据：L98 P2265；L107 P2503。

### 10.1 公司行为

公司行为是运行时事实，不是买卖信号：

- 任何可放弃订单都不得跨越已知的公司行为生效边界：生效前撤单并等待券商终态；终态前不发替代单。持续战略退出保留原 `intent_id`，但也必须撤掉旧价格订单；待券商权益到账、原始价格边界和调整因子更新、数量账本重算并对账后，才以新 `client_order_id` 和新的原始可交易价格续发；
- 有尚未应用并完成券商对账的公司行为时，暂停普通短差；战略退出和已确认的保护/恢复意图按全局优先级处理；
- 送股、转增、拆股、合股等强制数量变化，按当时官方权益和券商实到账同步缩放 `Q_CYCLE/Q_CURRENT/CORE/TACTICAL/pending_restore/locked/eligible` 及每个恢复批次数量，标记 `NON_TRADE_QUANTITY_TRANSFORMATION`；
- 现金分红按登记时实际持有的逻辑批次入账；已卖出且无权领取的恢复批次，把相应损失记入 `foregone_cash_distribution`，普通回补净差必须扣除；
- v3.0 不参加可选择的配股、供股或认购；券商默认行为不明确时停机，不凭主观判断增加股份；
- 公司行为缩放后若券商支持精确零股买入，待回补量保持精确值；否则把待回补总量向下取到买入数量增量，按 FIFO 保留前部批次，把最新批次尾部不可买余量转入 `corporate_action_unrestorable_restore_qty`，相应比例的恢复现金准备转回一般现金，并以 `Q_CYCLE=Q_CURRENT+可执行待回补量` 做非交易重基准；不得为凑整手而超买；
- 已持有但不能按普通卖出增量成交的短差零股改标 `CORE_ODD_LOT`，短差目标同步改为“可执行短差持有量＋可执行待回补量”。该变换必须标记 `NON_TRADE_CORPORATE_ACTION_NORMALIZATION` 并重新通过全部数量恒等式；
- `CORE_ODD_LOT` 不做普通短差；战略退出按券商允许的零股规则处理。买入增量、卖出增量和零股规则必须分别由运行时读取，不能假定都等于100股。

因此，“Q_CYCLE不增加”的准确含义是**不得因交易加仓**，不是忽略法定数量变换。

## 11. 订单状态机

### 11.1 合法状态

```text
O_IDLE
O_WORKING
O_PARTIAL
O_BLOCKED
```

一个标的同时只允许一个活动订单。每张订单必须有：

```text
client_order_id = strategy_version/parameter_set/symbol/rule_id/confirmation_time/sequence
intent_id
side
qty
limit_price
created_at
expires_at
persistence = OPTIONAL/PERSISTENT_EXIT
```

券商接受前即拒绝时，订单状态仍为 `O_IDLE`：可放弃意图立即关闭、释放预留并等待新结构；持续退出意图不得关闭，记录拒绝原因并转阻塞/修复后以同一意图新订单号重发。若拒绝原因显示价格、数量、费用或交易状态绑定错误，执行 `OPERATIONS_HALT_CANCEL_BUYS`，不得机械无限重试。

### 11.2 可放弃订单

战略入场、普通短差卖出、普通回补、三买保护和三卖后恢复买回都有结构价格上限/下限。有效期从信号确认柱收盘开始，到下一根L2柱收盘或当前连续竞价时段结束孰先：

- 只在连续竞价阶段发出；集合竞价阶段不延用上一时段的可选信号；
- 价格越过不利边界：不发单或撤单；
- 到期未成交：回 `O_IDLE`；
- 一次或多次部分成交：每个新 `execution_id` 分别更新；有效期内余量全部成交则关闭订单，到期仍有余量才撤销；
- 下一次必须等待新买卖点，不能沿用过期信号。

“确认柱高/低作为不利价格边界”“一根L2或时段结束的TTL”以及仅限连续竞价，都是把原文买卖点和“不追高”转换为真实订单的 `ENGINEERING` 规则，不是原文给出的订单参数。它们只能限制成交，不能创造或延长信号。

### 11.3 持续退出订单

战略全退、战略减半和L1三卖短差卖出属于风险退出：

- 不设盈利或成本价条件；
- 可在券商支持的集合竞价和连续竞价阶段执行；
- 使用交易场所当日合法最低卖价作为限价；没有日价格下限时，使用券商允许的最激进卖出限价。它只决定执行强度，不创造卖点；
- 日内订单保持排队；拒单、失效或下一交易日重发时保持同一 `intent_id`、生成新 `client_order_id`；
- 工作中或部分成交后的持续退出单若正常终止而目标未达到，直接以同一意图、新订单号续发；
- 停牌、跌停无成交或T+1阻挡时进入 `O_BLOCKED`；
- 恢复可交易后继续，直到目标持仓达到；
- 报单状态不得提前改写成已退出。

持续退出使用当日合法最激进限价是 `ENGINEERING/RUNTIME_FACT` 执行规则；卖出原因仍必须来自第8.3节或L26交易延续性边界，不能因盘口变化临时制造卖点。

### 11.4 对账与重启

每次启动、断线重连和成交回报后：

1. 拉取券商真实持仓、可卖量和活动订单；
2. 用成交编号去重；
3. 重算 `Q_CURRENT/tactical_held/pending_restore/locked`；
4. 不一致时进入 `OPERATIONS_HALT`；
5. 只有人工确认或确定性修复完成后恢复。

撤单请求不等于撤单成功；收到终态确认前不得发替代单。撤单途中晚到的成交仍按 `execution_id` 入账并重新运行优先级。订单更新乱序时以券商序号和单调累计成交量为准。启动时发现无法匹配 `client_order_id/intent_id` 的活动订单，或进程崩溃恢复时，先重放持久化事件日志，再与券商对账；未知订单必须人工分类，不能猜测后继续。

同一标的活动着低优先级可放弃订单时出现高优先级意图，统一执行：

1. 锁存高优先级意图及其原确认时刻，立即请求撤销旧单；
2. 旧单终态前不发替代单；所有晚到成交先按成交编号去重并更新真实仓位；
3. 终态后重算数量、现金、T+1和价格边界，再决定高优先级意图是否仍可执行；持续退出永不因等待而过期；可放弃的保护/恢复意图若已超过原TTL，只记录错过，不延长信号；
4. 战略全退或减半确认时，恢复义务已经终止。其后晚到的旧普通短差**卖出**成交只减少战略待处置仓位并记入 `terminated_restore_qty` 审计，不得重新增加 `pending_restore_qty`；晚到的旧买入成交计入真实仓位和战略退出/减仓目标，不得因此产生新的买入权；
5. L1三买保护取消普通卖单后，终态前晚到卖出仍按正常恢复批次入账，再由仍在TTL内的保护意图处理；L1三卖取消普通回补后，晚到买入形成真实短差库存并纳入持续风险卖出，若T+1锁定则保持阻塞。

### 11.5 历史撮合不得用“碰价即成交”

结构信号仍逐根已完成K线重放，但激活验收中的订单执行必须使用决策时点可得的逐笔成交和报价事件：

- 订单只能从模拟券商确认时刻之后参与；延迟取“实时模拟实测P95”和数据时间戳分辨率两者较大值，并在验证前冻结；
- 信号确认柱内发生过的价格和成交量不得用于该信号订单；
- 买限价只有后续真实成交价严格低于限价才算可成交，卖限价只有后续真实成交价严格高于限价才算可成交；只在限价上触碰视为排队位置未知，保守记零成交；
- 成交价统一按提交限价记账；可成交量不超过严格穿价后成交量的5%，再受订单余量和交易增量约束；
- 跌停/涨停仅在边界成交而无严格穿价时记零成交，不能假设风险退出必然卖得掉；
- 没有逐笔成交、历史报价或可冻结延迟模型的数据集，只能用于结构研究，不能用于真仓激活验收。

5%参与率是工程保守值。真仓账本永远只认券商实际成交；上述规则只用于避免历史回放虚构成交。

## 12. 全局唯一动作优先级

以下优先级先在**每个标的内部**折叠冲突：同一标的、同一结构快照只保留第一条命中的意图。它不是“全账户只准处理一只股票”。

1. 数据、券商或持仓对账故障：取消买单并 `OPERATIONS_HALT`；
2. 正式失去交易延续性：取消所有买单，启动或升级为持续全退；
3. 已存在持续战略退出订单：继续执行；
4. 新确认技术性战略全退：取消所有买单，启动全退；
5. 新确认战略减半：取消所有买单，启动减半；
6. L1三卖：停止回补或卖出短差库存；
7. L1三买保护：在高周期冻结政策允许时回补待恢复量；
8. 三卖后L1一买/二买恢复：仅在高周期政策允许时执行；
9. 普通短差卖出；
10. 普通短差回补；
11. 战略入场；
12. `HOLD/WAIT`。

随后账户调度器处理所有标的保留下来的意图：不同标的的持续退出可以同时工作；A股出现退出不会无条件冻结B股，只有账户级数据/对账停机、市场总闸门、现金、敞口或槽位约束才影响其他标的。所有买意图仍按上述类别优先级，再按确认时间、代码和意图号顺序逐一预留现金；高优先级恢复买入可撤销其他标的尚未成交的低优先级战略入场预留，仍不足则缩量或等待，绝不借款。每个标的始终最多一个活动订单。

同一时刻：

```text
L0结构 > L1结构 > L2定位
高周期只拥有入场门和普通回补门，不覆盖个股L0退出
已经存在的持续退出意图 > 新买入意图
已有周期的恢复买入 > 新战略入场；恢复买入不受“新仓90%”门，但受真实现金和Q_CYCLE上限
```

账户内多个同优先级意图同时发生时，统一按 `confirmation_time` 从早到晚、证券代码字典序、`intent_id` 字典序；现金按该顺序预留，后续意图只能缩量或等待，不能人工挑选。

## 14. 每日执行流程

### 开盘前

1. 券商持仓、可卖量、现金和活动订单对账；
2. 更新点时复权因子、公司行为事件及生效边界、交易日历、价格边界和停牌状态；
3. 用已完成数据更新月/周/日分型、5周期线和市场风险门；
4. 更新板块分类、历史成分和强弱排序；
5. 更新每只持仓的L0状态、L1中枢版本和数量账本；
6. 标记持续退出、待恢复、当日锁定和禁止新增标的；
7. 任一运行时契约失败，保持 `LIVE_DISABLED/OPERATIONS_HALT`。

### 盘中

1. 每根L2 K线收盘更新定位；
2. 每根L1 K线收盘更新短差中枢阶段；
3. 每根L0 K线收盘更新战略状态；
4. 运行第12节优先级；
5. 先生成意图，再生成订单；只有成交回报才能改变数量；
6. 每次成交立即做券商对账；
7. 未完成结构只观察，不下单。

### 收盘后

1. 保存全部候选、否决、意图、报单、撤单、拒单和成交；
2. 保存当时可见的结构与账户快照；
3. 分开核算战略收益、普通短差、保护性负差和未恢复筹码；
4. 检查是否动用CORE、超过Q_CYCLE、重复报单或无买点回补；
5. 检查全部状态不变量；
6. 当日发现核心违规，下一交易日自动 `LIVE_DISABLED`。

## 15. 上线验收门

顺序不可交换：

1. 规则版本和工程参数签名冻结；
2. 静态图人工标注与双人/双实现一致性检查；
3. 本文规则的冻结实现通过全部规则一致性场景；本版静态验收结果见第20.1节；
4. 历史结构逐根回放，并按11.5节逐事件撮合，不使用未来数据或“碰价即成交”；
5. 独立留出区间验证，不允许重新调参；
6. 至少60个交易日实时模拟；
7. 每日券商模拟账户对账；
8. 验收阈值全部通过；
9. 才能人工签名启用真仓。

v3.0 工程最低样本：

```text
historical_strategic_cycles >= 100
historical_tactical_cycles  >= 200
realtime_paper_days         >= 60
undefined_state_transitions == 0
core_intrusions             == 0
Q_CYCLE_breaches            == 0
duplicate_orders            == 0
broker_reconciliation_diff  == 0
deterministic_repeatability == 100%
net_result_after_all_costs  > 0
profit_factor               >= 1.20
max_account_drawdown        <= 12%
```

这些门槛是 v3.0 工程验收值，不是缠论原文承诺。第9课要求用长期数据检验程序失效率；第50课要求先静态分析、再当下模拟、有把握后才真实买卖。任何一项失败，保持 `LIVE_DISABLED`。

## 16. 永久禁止项

- 借款、融资、加杠杆；
- 入场订单关闭后增加 `Q_CYCLE`；
- 用L2信号处置CORE；
- L1中枢上移时做同级别普通短差；
- 未完成结构、事后重画或理论极值冒充当时信号和成交；
- 采用新笔，或用未处理原始K线数量替代旧笔“至少一根独立处理后K线”的成立条件；
- 三卖后按成本价、跌幅或希望普通回补；
- 错过买点后追价；
- 用MACD、均线、分型、板块排名、Zn或历史振幅单独下单；
- 用可卖的CORE替代被锁定的TACTICAL；
- 参数冻结后根据单笔盈亏盘中修改；
- 对账不一致时继续新买；
- 用人工改单、手工交易或盘中临时解释绕过本文唯一意图、限价、数量、优先级或持续退出；
- 未通过验收门便启用真仓。

### 18.4 数量、限价与订单检查

新入场先算：

```text
U_SLOT   = 账户权益 * 18%
U_REMAIN = max(0, 账户权益*90% - 当前总市值
                  - 待恢复敞口承诺 - 已预留战略入场名义额)
Q_PLAN   = min(槽位整手量, 剩余敞口整手量,
               含最坏费用的现金可负担量, Q_LIQUIDITY_CAP)
```

所有买路都必须满足：

```text
q * buy_limit + bound_buy_cost(q,buy_limit)
<= 未预留券商可用现金
```

`bound_buy_cost` 必须包括最低佣金、舍入和全部买方税费。入场单终态后以实际初始成交量设 `Q_CYCLE`，余量永不追补；`TACTICAL_TARGET=floor_to_lot(0.25*Q_CYCLE)`，不足一个交易单位则关闭短差。

普通短差发单前还要核对：最近20个完整结构配对至少5个，严格回放未成交样本未被删除，较低中位 `net_edge_ticks >= 1.0`；随后当前回补单的每个可能部分成交前缀仍须逐批覆盖实际成本。

可放弃订单只在连续竞价发出，到下一根L2收盘或当前连续竞价时段结束孰先到期；越过不利价格边界即不发或撤余单。持续退出不以盈利、成本或TTL为条件，正式阻塞解除后以同一意图、新订单号续发。撤单请求不等于撤单成功，收到终态前禁止替代单；晚到成交照常入账。

已知公司行为生效前，任何活动订单都必须撤销并等待终态。生效后先应用官方权益/券商到账，更新原始价格边界和调整因子，重算全部数量并完成券商对账；可放弃意图作废，持续退出保留原意图但按新价格、新订单号续发。

### 18.5 止盈、止损与账户风险的准确边界

本画像不设置任意百分比止盈、固定价格止损或移动止损，因为原文买卖权来自相应级别已完成的买卖点、背驰和三买/三卖。战略退出条件一旦完成，不因亏损、盈利或成本价而延迟；条件未完成，也不能拿主观恐惧制造技术卖点。

10%账户回撤线是 `ENGINEERING` 新开仓暂停门，只阻断新增战略仓，不直接卖出现有仓位；历史/模拟最大账户回撤不超过12%是上线验收门，也不是卖点。数据、券商、对账和市场微观结构故障属于操作停机，不属于行情止损。
